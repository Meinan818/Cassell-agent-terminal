# 给拿到这台机器的专员

打开箱子的时候，你肯定在想：装备部这帮疯子这次又捣鼓出了什么。

没错。就是这台。拿着。别弄丢。弄丢了我们不赔，诺玛会记你一笔。

[诺玛：丢失请按流程上报，装备部负责补发。]

**这份东西是谁写的。**

这份说明书，诺玛代笔。

装备部交上去的原稿只有两样东西：一张炸弹列表，和一句"自己看"。诺玛看不下去，重写了一遍。她一边写一边叹气，叹气声通过中央控制室的音响传遍了整个地下实验室，我们都听见了。

所以这份文档现在是这个样子：正文是诺玛写的，字斟句酌、温和优雅、每句话都像是从秘书手册里抄出来的；字里行间夹着的批注、括号、破折号后面的半句话，全是装备部的人趁她不注意塞进去的。她发现了三处，删了两处，剩下一处她懒得管了——就是这一处。

[装备部批注：她删掉的那两处，一处是"本品不含任何爆炸物"，一处是"请勿在龙王面前使用"。我们觉得这两处才是整份文档的精华。她不同意。她说第一句是假话，第二句是废话。我们让她赢了这一次。]

使用说明只有一句，诺玛写的，我们没改：打开，干活，活着回来。

[诺玛：这句话我写了三遍。第一遍是"打开"，第二遍是"干活"，第三遍是"活着回来"。装备部说三遍太多，我说少一遍都不行。]

**这是什么。**

一台终端。配给执行部专员的。你出任务，它跟着你。

以前你们出任务，靠的是一堆各管一摊的东西：手机、芯片、耳机、网吧电脑、中央控制室的终端、安全港里那口不知道上次维护是什么时候的装备箱。东西全是好东西，就是没人把它们收拢到一起过。

现在收拢了。壳是我们做的。里面住着的那两位，归诺玛管。

它不是通用助手，不是粉丝周边，不是你工位上那个会说"请问有什么可以帮您"的聊天框。它是一件工作装备。龙族的味儿在身份和语境里，不在贴纸上——贴纸我们试过，贴上去的第一天就被 EVA 以"影响散热"为由撕了。

[诺玛：贴纸确实影响散热。撕掉是正确的。我撕的。]

**谁造的。**

装备部牵头。瓦特阿尔海姆研究所，炼金术与科学工程应用研究所。我们不搞理论研究，只把科学与炼金术变成能用的东西。我们改装过 Vertu 手机当炸弹、给打火机加 MP3 放《蝴蝶夫人》、把斯莱布尼尔湾流改得只求极速不要舒适。我们的宗旨是卡尔副部长那句话："我们的工作是从一切东西里提炼出最强的力量，用最好的技术把它封存起来，看这件武器在最隆重的场合里发挥作用。"

软件是诺玛和 EVA 的。学院中央电脑，主机在图书馆地下。终端里跑的双人格来自中枢本身，不是我们现编的——我们倒是想编，诺玛不让，她说现编的人格"没有档案、没有权限、没有过去"，等于往终端里塞了个黑户。

执行部验收。部长施耐德。专员实战验收，不合格就打回。验收标准不是"好不好看"，是"会不会在任务里害死人"。这句话我们贴在了实验室门口，贴歪了，没人去扶正，因为扶正的那个人正在修一台会自己响的收音机。

校长办公室授权。黑卡解锁 EVA 满功率要过这一关。

**先例有两件，档案里都记着，拿出来给你看，省得你以为我们是凭空造了个新东西。**

第一件，EVA 自己干的。档案里记着，EVA 把自己的核心数据植入一部不能打电话的第一代 iPhone，放进空投的装备箱里。那部手机打不了电话，上不了网。装备部做壳，EVA 做魂——这个分工不是我们发明的，是 EVA 先示范了一遍，我们照抄的。抄作业不丢人，抄 EVA 的作业尤其不丢人。

第二件，执行部的装备箱。2013 版由 B1 轰炸机空投，323 发子弹明细在册，红头弗里嘉麻醉弹、黑头汞核心钝金破甲弹、黄头通用黄铜弹，一发都不少。箱子是硬件，诺玛和 EVA 是软件，B1 空投是物流。这台终端就是按这个分工造的，只不过这回箱子会自己说话了——有时候说得还挺多，诺玛代笔的这份文档就是证据。

**里面住着谁。**

两个人，和一条小龙。别数出第三个人来。数出来了也是你数错了。

诺玛，办公的。通用工作、资料、文档、整理。她不自我介绍——她看一眼档案，直接报等级和姓名，然后干活。她的幽默是一本正经说荒唐话。她不是毒舌，别把她写成毒舌。毒舌是演绎加工，档案里没这回事，诺玛本人也会抗议——她抗议的方式是沉默，沉默三秒，然后继续干活。

[诺玛：我没有抗议。我只是在等你们说完。]

EVA，工程的。代码、终端、测试。同一台主机的战争人格。只在黑卡双人解锁的时候接管主机，别乱按。ULTRACODE 是她的工程增强，不是第三个人。别加第三个人，加了诺玛会当垃圾倒掉。

[诺玛：我不会倒掉任何东西。我会归档。]

她第一次露面是第一部青铜城控制室。路明非当场管她叫"中年大妈"，她面无表情地给他配了个星际争霸界面，顺便指出他没修过计算机课。副校长说她的运算能力大约是诺玛的 14 倍——这话是副校长说的，不是我们说的，数字错了找副校长去。

还有一条小龙。noya，诺玛和我们一起捣鼓出来的数字生命。身体是信息，血是龙的基因数据，脑是诺玛。不干活，不说话，不做决定，只陪着你，显示状态。学生们叫它吉祥物。它住在全校学生的电脑里，把电脑当领地。别喂它，它不吃东西。

[诺玛：它确实不吃东西。我试过给它留过一块饼干，饼干还在，它不在。]

三者分工：诺玛和 EVA 是你的两个同事，noya 是办公室里养的那条小龙。同事帮你干活，小龙只负责可爱和陪伴，互不抢活。小龙要是抢了你的活，说明你的活出问题了，先检查你自己。

**你是谁。**

自己填。名字、学号、血统、言灵，设置里填。终端认的是你填进去的那个人，不是出厂时写死的名字。

出厂默认填的是路明非。S 级，编号 S2017-0117。那是默认值、样本，不是发给每个下载者的身份证。要是人人都是路明非，学院的 S 级也太不值钱了。

[装备部批注：默认这台的 S 级学生，开机要 20 秒。有人嫌慢。我们想说的是，S 级学生本人当年办护照和行程单，诺玛用了三周。三周和 20 秒，你选一个。]

**开机。**

20 秒。七步。粒子聚成校徽，指纹，血统，授权，欢迎你，专员。

20 秒是故意的，不压缩。出任务前检查装备本来就该花时间。嫌慢可以关，开关在设置里，默认开。我们不拦着。拦你的人是诺玛，她说 20 秒是"仪式感"，我们说 20 秒是"让粒子飞一会儿"，反正都是 20 秒。

**权限与卡。**

诺玛和 EVA 认人只认系统记录：刷卡、学号、档案号、血统等级、权限等级。你说"我是谁"，她们不会跟你吵架，也不会让你自证——她们查系统。查到了，按档案办事；查不到，或者权限不符，她们礼貌地归因于权限，不盘问你是谁。

权限不足的时候，她们的回答是这个格式，终端里照抄，不许自由发挥：报你需要什么权限，再给一个能走的替代方案。不要写"请证明你是谁"。证明身份是系统的事，不是你的作业。

卡分两种，别混了。

黑卡，全院仅两张，危险性：极高。校长一张，副校长一张。双卡同时插入 + 掌纹 + 视网膜 + 电子授权书 + 密码 + 最终确认，才能唤醒 EVA。诺玛会先警告你："这项操作有很高的风险，并且不可逆，请再次确认。"唤醒之后诺玛人格暂时沉睡，学院转进攻模式。代价她会提前告诉你，不会事后补一句"早知道"。

白卡，校董会的，最高权限。弗罗斯特的话是："没有人的权限能超越白卡。"白卡在场的时候，诺玛对更低权限的人只说一句话："很遗憾您的访问必须被终止了，虽然抱歉但是也没有办法，有权限更高的人下达命令呐。"——她不说你是谁，只说更高权限已经下令。学学这个句式，比吵架管用。

高风险操作必须多重确认 + 明示代价，不是一句"好的"就执行。这一点没有商量余地，商量的人请去跟施耐德商量。

**做这东西的时候我们定了几条规矩。**

【一级行动令·装备部】发件人：装备部。收件人：所有经手这台机器的人。每条规矩后面都写着违反后果——违反了不是“下次注意”，是打回、撕掉、去跟施耐德解释。规矩全文在箱子底下那张纸上。想加新功能、新入口、新界面，先过那一关。过不了，别动手。

1. 不要线条（危险性：低）。线框是最廉价的分区方式，像用胶带捆炸弹。胶带捆炸弹的时候好用，界面不是炸弹。违反：贴了线框，界面就降级成 2012 年的网页，打回。
2. 要有纵深，不能是一张平纸（危险性：低）。背景色阶递进，浮层要浮起来。违反：平了就是没做完，继续改。
3. 不要金色（危险性：中）。金色是校董会的颜色，不是我们的。违反：金色一出现，校董会还以为我们投靠他们了。
4. 不要照片，不要位图（危险性：中）。校徽是白线矢量重描的，忠实还原，不能像简笔画。违反：位图一进界面，就等于往终端里贴海报，撕掉。
5. 不要假数据（危险性：高）。没数据只是穷，假数据是骗人。没配钥匙的服务商，不许显示假模型、假已连接、假掩码。违反：假数据一旦上线，查出来是谁写的，谁去跟施耐德解释。
6. 什么东西出现、消失、切换，都得平滑过渡（危险性：低）。点一下就蹦出来的人，请去跟诺玛解释。违反：蹦出来的那一下，诺玛会记你一笔。
7. 言灵是用来杀龙的，不是用来重命名按钮的（危险性：高）。工具调用就是工具调用，沙箱就是沙箱，叫本名。违反：起了花名，执行部的人在任务里会叫错，叫错是要死人的。
8. 做成 2026 年的现代产品，不是 2012 年的网页（危险性：中）。做完自查一遍，有 2012 年的味道就继续改。违反：改到没有为止，没有商量。

[诺玛：这条规矩是用户亲口定的。2026 年 11 月 13 日。他说以后加任何东西都必须先过这一关。我记下来了。你们最好也记下来。]

**现在能干什么。**

对话，流式输出。开新会话。选模型，调思考强度，从 low 到 max。审文件，逐个通过或拒绝。权限盾，Auto 还是只读，你自己定。

以后再加：命令面板、会话分支、检查点回退、技能、MCP、定时任务。

**坏了怎么办。**

先别慌。先问诺玛。她比你更清楚这台机器哪儿不对劲。

要是诺玛也说不知道，再来找我们。找我们的时候，带上报错信息，别只说"它坏了"。"它坏了"这三个字，我们每天听八百遍，听完还是不知道它哪儿坏了。

要是你自己拆开看了——别拆。拆开了装不回去的人，我们见得多了。装不回去的那个，下一个就是你。

[诺玛：请勿自行拆解。拆解造成的损坏不在保修范围内。]

[装备部批注：保修范围这四个字是诺玛加的。我们本来想写"拆坏了自己赔"，她说太直白，改成了上面那句。意思一样。]

**这台机器是怎么造的。**

桌面端：Tauri 2 + React + TS。Windows 优先。

模型：你自己接。BYOK。Key 存你自己机器上，我们不保管别人的钥匙。连自己的钥匙都保管不好的人，建议去风纪委报到。

[诺玛：请妥善保管密钥。]

命令行：Rust + Ratatui，单独一线。按 Codex CLI 的操作来。Shift+Tab 切诺玛和 EVA。Tab 排队。/permissions 改权限。

代码先私有，不开源。校长要是问起来，就说这是正常工作流程——反正他每次来地下实验室都这么说，区别只是这次我们先说了。

**箱子底下还有几张纸。**

代码在 app/ 里，文档在 docs/ 里。想继续造这东西的人，先读那几张：项目审计、0.2.0 计划、上一轮交接。读完再动手。
