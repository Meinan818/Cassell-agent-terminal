# 给拿到这台机器的专员

打开箱子的时候，你肯定在想：装备部这帮疯子这次又捣鼓出了什么。

没错。就是这台。拿着。别弄丢。弄丢了我们不赔，诺玛会记你一笔。

[诺玛：丢失请按流程上报，装备部负责补发。]

这份东西是诺玛代笔的。她写得比我们像人。我们趁她不注意，在上面加了点东西。她发现了，删了两处。剩下的，她懒得管了。我们也是。

**这是什么。**

一台终端。配给执行部专员的。你出任务，它跟着你。

以前你们出任务，靠的是一堆各管一摊的东西：手机、芯片、耳机、网吧电脑、中央控制室的终端、安全港里那口不知道上次维护是什么时候的装备箱。东西全是好东西，就是没人把它们收拢到一起过。

现在收拢了。壳是我们做的。里面住着的那两位，归诺玛管。

**里面住着谁。**

两个人。别数出第三个。数出来了也是你数错了。

诺玛，办公的。通用工作、资料、文档、整理。她不自我介绍——她看一眼档案，直接报等级和姓名，然后干活。她的幽默是一本正经说荒唐话。别把她写成毒舌，档案里没这回事。

EVA，工程的。代码、终端、测试。同一台主机的战争人格。只在黑卡双人解锁的时候接管主机，别乱按。ULTRACODE是她的工程增强，不是第三个人。别加第三个人，加了诺玛会当垃圾倒掉。

[诺玛：我不会倒掉任何东西。我会归档。]

还有一条小龙。noya，诺玛和我们一起捣鼓出来的数字生命。身体是信息，血是龙的基因数据，脑是诺玛。不干活，不说话，不做决定，只陪着你，显示状态。学生们叫它吉祥物。它住在全校学生的电脑里，把电脑当领地。别喂它，它不吃东西。

**你是谁。**

自己填。名字、学号、血统、言灵，设置里填。终端认的是你填进去的那个人，不是出厂时写死的名字。

出厂默认填的是路明非。S级，编号S2017-0117。那是默认值、样本，不是发给每个下载者的身份证。要是人人都是路明非，学院的S级也太不值钱了。

**开机。**

20秒。七步。粒子聚成校徽，指纹，血统，授权，欢迎你，专员。

20秒是故意的，不压缩。出任务前检查装备本来就该花时间。嫌慢可以关，开关在设置里，默认开。我们不拦着。拦你的人是诺玛，她说20秒是仪式感，我们说20秒是让粒子飞一会儿。

**做这东西的时候我们定了几条规矩。**

不要线条。线框是最廉价的分区方式，像用胶带捆炸弹。胶带捆炸弹的时候好用，界面不是炸弹。

要有纵深，不能是一张平纸。背景色阶递进，浮层要浮起来。

不要金色。金色是校董会的颜色，不是我们的。

不要照片，不要位图。校徽是白线矢量重描的，忠实还原，不能像简笔画。

不要假数据。没数据只是穷，假数据是骗人。没配钥匙的服务商，不许显示假模型、假已连接、假掩码。

什么东西出现、消失、切换，都得平滑过渡。点一下就蹦出来的人，请去跟诺玛解释。

言灵是用来杀龙的，不是用来重命名按钮的。工具调用就是工具调用，沙箱就是沙箱，叫本名。

做成2026年的现代产品，不是2012年的网页。做完自查一遍，有2012年的味道就继续改。

规矩全文在箱子底下那张纸上。想加新功能、新入口、新界面，先过那一关。过不了，别动手。

**现在能干什么。**

对话，流式输出。开新会话。选模型，调思考强度，从low到max。审文件，逐个通过或拒绝。权限盾，Auto还是只读，你自己定。

以后再加：命令面板、会话分支、检查点回退、技能、MCP、定时任务。

**这台机器是怎么造的。**

桌面端：Tauri 2 + React + TS。Windows优先。

模型：你自己接。BYOK。Key存你自己机器上，我们不保管别人的钥匙。连自己的钥匙都保管不好的人，建议去风纪委报到。

[诺玛：请妥善保管密钥。]

命令行：Rust + Ratatui，单独一线。按Codex CLI的操作来。Shift+Tab切诺玛和EVA。Tab排队。/permissions改权限。

代码先私有，不开源。校长要是问起来，就说这是正常工作流程。

**箱子底下还有几张纸。**

代码在app/里，文档在docs/里。想继续造这东西的人，先读那几张：项目审计、0.2.0计划、上一轮交接。读完再动手。
