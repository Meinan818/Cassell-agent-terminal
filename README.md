# 卡塞尔专员终端（Cassell Agent Terminal）

> 瓦特阿尔海姆研究所出品。装备部牵头制造，诺玛 / EVA 中枢提供软件，执行部验收，校长办公室授权。
>
> 早期开发中。代码先私有，不开源。校长要是问起来，就说这是正常工作流程。

## 这是什么

一台配发给执行部专员的随身终端。专员出外勤的时候，手机、芯片、耳机、网吧电脑、中央控制室终端——以前这些东西各管一摊，现在收进一台机器里。

它不是通用助手，不是粉丝周边。它是一件工作装备。龙族的味儿在身份和语境里，不在贴纸上。

使用说明：打开，干活，活着回来。

装备部平时连张说明书都不给，有时连句解释都没有，只给一张炸弹列表。这份是破例——诺玛代笔的，她看不下去我们把一台终端交出去连张纸都不附。

## 出身：谁造的

- **整机与硬件：装备部（瓦特阿尔海姆）牵头。** 炼金术与科学工程应用研究所，部长阿卡杜拉。我们不搞理论研究，只把科学与炼金术变成能用的东西。原作里我们改装过 Vertu 手机当炸弹、给打火机加 MP3 放《蝴蝶夫人》、把斯莱布尼尔湾流改得只求极速不要舒适、东京决战打开装备箱组装电脑、15 分钟接管东京都气象局、15 分钟解析天谴启动程序。这台终端是同一路数：日常物，做出乎意料的功能，过度工程。卡尔副部长的话是我们的宗旨：“我们的工作是从一切东西里提炼出最强的力量，用最好的技术把它封存起来，看这件武器在最隆重的场合里发挥作用。”
- **软件、AI 与双人格：诺玛 / EVA 中枢本身。** 学院中央电脑，主机在图书馆地下。诺玛是秘书，EVA 是同一主机的战争人格，黑卡双人解锁满功率。终端运行的双人格来自中枢本身，不是我们现编的。
- **需求、验收与分发：执行部。** 部长施耐德。专员实战验收，不合格就打回。执行部的验收标准不是“好不好看”，是“会不会在任务里害死人”。
- **立项与授权：校长办公室（+ 校董会）。** 黑卡解锁 EVA 满功率要过这一关。（学院黑卡，全院只有两张。不是恺撒那张银行卡，别混了。）

说清楚一件事：原作里并没有一台叫“专员终端”的成品。专员以前用的是分散的手机、芯片、耳机、网吧电脑和中央控制室终端。这台机器是把那套东西收拢成制式装备——是补完，不是原作事实。最接近的先例在《龙族Ⅴ》：EVA 自己把核心数据植入一部不能打电话的第一代 iPhone，放进空投的装备箱里。更直接的先例是执行部的装备箱：2013 版由 B1 轰炸机空投，323 发子弹明细在册——箱子是硬件，诺玛/EVA 是软件，B1 空投是物流。装备部做壳，EVA 做魂。这台终端就是按这个分工造的。

## 编制：终端里住着谁

- **NORMA（办公）**：学院中枢 AI 的秘书人格。对标 Claude Cowork：通用工作、资料、文档、整理。诺诺的原话是“什么事情交给她就好了，她绝对一流”。她是诺玛本人换了个工位，不是新造的人格。她说话是温和优雅的沉稳女声，固定开场是“我是诺玛，卡塞尔学院秘书，很高兴为您服务”。她的幽默是死板的、一本正经说荒唐话——“我打开了门，正在倒垃圾”“在龙类学会使用电脑前，我认为自己还是安全的”“下一次倒垃圾在十七年之后”。她不是毒舌，别把她写成毒舌。
- **EVA（工程）**：同一主机的战争人格，100% 状态。对标 Claude Code：工程、代码、终端、测试。原作里她只在极端紧急情况、两张黑卡授权下接管主机，设计初衷是进攻武器。ULTRACODE 是她的工程增强，不是第三模式——原作里也没有第三个人格，别加。战时她说话是极简短句、直接下令：“已经熟悉完毕，已经读完列表任务，对辉夜姬的进攻从现在开始。”苏醒的瞬间就用高温过载烧毁了封锁她的芯片组。
- **noya（吉祥物）**：诺玛和装备部一起捣鼓出来的终端版数字生命。身体是信息，血是龙的基因数据，脑是诺玛的 AI。龙数据 + AI 的数字混血种。类似绘梨衣的底牌性武器（绘梨衣是人型底牌，noya 是龙型底牌）。对人类友善，对龙类和坏人不友善，听执行部专员。心智是个小孩，但小孩不等于弱。它住在全校学生的电脑里，把电脑当领地。它不干活、不说话、不做决定，只陪着专员、显示状态。学生们叫它吉祥物。原作里没有叫 noya 的龙，这是产品原创，写明了，不装原作。

三者分工：诺玛和 EVA 是你的两个同事，noya 是办公室里养的那只猫。同事帮你干活，猫只负责可爱和陪伴，互不抢活。

## 技术路线

- 桌面端：Tauri 2 + React + TypeScript，Windows 优先。
- 模型路线：BYOK——不由软件定一家模型，用户自己配置 API Key 接入干活，支持 DeepSeek、Kimi、千问、GPT 等多家。Key 存本地。Key 在你自己的机器上，不在我们这儿。装备部不保管别人的钥匙。
- CLI：Rust + Ratatui，单独一线。设计已定稿，见 `docs/cli-design/`；操作模式按 OpenAI 的 Codex CLI（Shift+Tab 切 NORMA/EVA，Tab 排队，`/permissions` 改权限）。

## 设计语言

铁律，用户 2026-11-13 亲口定：以后加任何新功能、新入口、新界面，都必须先过这一关。全文见 [`docs/FRONTEND-PHILOSOPHY.md`](docs/FRONTEND-PHILOSOPHY.md)。这里是装备部版的速读：

- **现代极简高级，像一个活的产品在呼吸，不是静态页面。** Codex 式简洁，白黑双主题，全圆角（不要直角）。目标是 2026 年的现代产品，不是 2012 年的网页。做完自查一遍：有没有残留 2012 年的味道，有就继续改。
- **不要线条，不要线框感。** 分区、分组、卡片，一律不用 1px 框线。用间距、背景色阶、细腻阴影、字重层级建立层次。线框是最廉价的分区方式，像用胶带把装备捆在一起。
- **要有纵深和层次，不能是一张平纸。** 背景色阶递进、细腻阴影与浮起感，每一处分区、每一个浮层都要有纵深感。
- **不要金色。** 全站禁用金色/黄色。强调色只用诺玛墨色与 EVA 蓝。金色是校董会的颜色，不是装备部的。
- **界面里不要照片，不要位图图片。** 素材一律用线条矢量、纯色、粒子。校徽用白色线条矢量 CrestLine，忠实还原真校徽，不能像简笔画。
- **不许任何功能“点一下就蹦出来”。** 出现、消失、切换，一律平滑过渡（150–350ms、缓动自然）。没有例外。
- **全站都要有灵动感和生命感。** 不只是对话区那几处，整个应用都要活起来。标准：打开第一眼就觉得是一个活的产品在呼吸。保持极简克制、灵动不花哨、快不拖沓。
- **动画设计语言对标 Grok Bot**：全站统一运动系统（一套弹簧参数、所有状态变化有过渡、控件有按压/悬停反馈、60fps 只动 transform/opacity）。
- **活标记**：诺玛与 EVA 共用同一圆球形象，只以颜色与表情区分（诺玛墨色，EVA 蓝色）；眼睛是小药丸形，长在球面上。
- **AI 输出消息为 GPT 式流式输出**（逐字流出、带光标）。流式光标是蓝色圆点（8px、#60a5fa、呼吸脉冲），不是竖条。
- **字体与细节**：Inter + 思源黑体；身份卡是横向名片比例，S 印章是优雅衬线 S + 1px 发丝圆环，无实心圆底，不要“血统评级”文字。
- **不许假数据。** 从空状态开始，每个功能端到端真正能用。未配 Key 的服务商不能显示假模型、假已连接、假掩码 Key、假时间。
- **功能叫本名。** 工具调用就是工具调用，沙箱就是沙箱。不硬套言灵等设定。言灵是用来杀龙的，不是用来重命名按钮的。
- **动效（装备部式，2026-11-15 定）**：欢迎卡逐行浮现、工具行从左边滑入、任务完成 ✓ 亮一下、错误行左右轻抖两下像被电了一下。灵动，但不花哨。

## 开机仪式

白色细粒子螺旋汇聚成卡塞尔校徽，接指纹身份验证、S 级血统、ACCESS GRANTED，最后落到「欢迎你，专员」。开机七步约 20 秒，是故意设计的，不压缩。设置里有启动动画开关（默认开）。

20 秒很长？出任务前检查装备本来就该花时间。嫌慢可以关，开关在设置里，我们不拦着。

## 最小可用版本（MVP）

- 对话（流式输出）+ 新会话空态（活标记、专员问候、建议芯片、上下文栏）
- 模型选择器（服务商:模型 + 思考强度 low→max，EVA 并行档）
- 权限盾：审批模式（Auto / 只读）+ 沙箱模式（read-only / workspace-write / danger-full-access）
- 审查队列：Changes 增减统计、逐文件通过/拒绝
