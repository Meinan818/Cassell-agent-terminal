# Grokbot 动画规范（卡塞尔专员终端 · 美术圣经）

> 依据：① 咱们自己的参考文件逐帧实测（`style-ref/grokbot-hero.gif`，340×340，68 帧，3.4s @ 20fps；`grokbot-pebble-blue.png`；`grokbot-round-teal.png`）；② 公开研究：xAI 官方设计博客（2026-09-03）、jeremy-prt/bloub（MIT，逐帧逆向工程）、erickirt/frosted-ui 研究笔记、nasawz/GrokBot 与 grokbot-web、Novra Rive 案例、Vibecode 实测。
>
> 直径统一用 **D** 表示（圆球直径）。所有"%"都是相对 D 的比例，便于按任意尺寸换算。
>
> **先说最重要的三句纠正（实测结论，与咱们现有的做法有出入）：**
> 1. **Grokbot 不用弹簧做圆球/表情过渡。**实测是**指数缓出、无超调**；全系统唯一带超调的是通知小点弹出（+14%）。咱们现有的弹簧参数离这个已经很近（见 §5），只需把阻尼提到临界值。
> 2. **圆球本体永远是正圆，不挤压、不浮动。**生命感来自**眼睛**（注视漂移 + 眨眼），不是身体上下浮动、不是把身体压成椭圆。实测身体中心 3.4 秒只动 ±1px，宽高比恒 1.00–1.01。
> 3. **状态由圆球本身的运动编码**（idle / thinking / working / waiting / blocked / done），不另加状态灯；xAI 明确拒绝了"三个跳动圆点"作为思考指示。聊天区那三个小指示器（思考/探索/起草）是另一层东西，见 §4b。

## 1. 圆球本体

### 1.1 形状与位置
- **正圆**，径向偏差 < 0.7%。直径 D 为基准单位。
- **中心固定，不上下浮动。**实测（hero GIF，340px 画布）：3.4 秒内中心 x 只在 168.7–170.7 之间（±1px ≈ ±0.5% D），y 恒为 169.4–169.5（几乎不动）。研究结论一致：静止时中心稳定到 ±0.003 倍半径。**禁止 bob（上下浮动）。**
- 眼睛是"洞"（用 mask 从身体上抠出），滑到边缘时会被身体轮廓裁剪，绝不溢出身体。

### 1.2 呼吸（均匀缩放，禁止宽高比变形）
- 身体**只做均匀缩放**，宽高比恒为 1。实测 hero GIF 全程 h/w = 1.00–1.01，**从未出现椭圆**。
- Hero 循环实测：直径 204 → 218 → 204，即 **+6.9%**，约 1.4s 吸入、短暂停顿、约 1.4s 呼出，3.4s 一个循环。这是偏"活跃/问候"的呼吸幅度。
- 待机微呼吸（研究实测）：**0.5%**，只为让画面不完全冻结。
- 落地分档：
  - 待机 idle：**±0.5%**，周期 3.4s（吸入 1.4s + 呼出 1.4s + 停顿 0.6s）。
  - 工作到来 / 进入状态（"kicks into gear"）：一次 **+2%～+6.9%** 的均匀缩放脉冲，0.3s 指数缓出，作为"收到任务"的确认信号；不要循环。
- **禁止** `scaleX ≠ scaleY` 的身体变形。身体的"挤压拉伸"不存在；挤压拉伸只发生在眼睛（§2.4 眨眼、§3 表情变形）。

### 1.3 倾斜与转动
- 圆球本体**不整体旋转、不倾斜**。倾斜体现在"眼对"的整体倾斜上（§2.3），不是身体变形。
- 头部转动（turn）：眼睛按球面投影移动（§2.2），身体不动。转到球体背面时眼睛消失（被身体遮挡）。
- 各状态自带一个头部倾斜角（roll）：rest 为 **-13°**，wink 为 **+6.7°**。状态切换时倾斜角会跳变——这正是要用眨眼遮盖切换的原因（§3）。

### 1.4 出场（arrival）
- 球单独出现在中央，**眼睛绕球转满一圈**（看起来像原地自转），然后滑入位置，同时界面在它周围出现。
- 出场只播 **idle** 状态。任何其他状态都自带注视姿态，会在切换时造成眼睛跳变（实测两帧之间跳 15px），而 0.2s 的眨眼遮不住 0.3s 的入场淡入，会读成"瞬移"。
- 入场淡入 **0.3s**。整圈旋转 **1200ms**（spin 一整圈的标准时长）。
- 出场时球是正圆（眼睛贴在真实轮廓上才不会跳；非圆形状上眼睛会上下跳最多 25px）。
- `prefers-reduced-motion` 下不出场动画，直接显示终态。

## 2. 眼睛

### 2.1 尺寸与位置（实测 + 产品已批准值）
| 指标 | Grokbot 实测（hero GIF，D=204） | 产品已批准 |
|---|---|---|
| 单眼宽 | 25px ≈ **12% D** | **20% D** |
| 单眼高 | 57px ≈ **28% D** | **30% D** |
| 高宽比 | **2.28**（竖直胶囊） | 约 1.5（更粗的药丸） |
| 两眼中心间距 | 63px ≈ **31% D** | 间距拉开（已定） |
| 单眼中心距球心 | ±31.5px ≈ **±15% D** | 同左 |
| 垂直位置 | 与球心等高（眼中心 y = 球心 y） | **上半部** |

- 形状：**竖直胶囊（药丸）**，无高光。浅色底用黑瞳、深色底用白瞳（按底色反色）。
- 眼睛是"洞"不是贴片：用 mask 从身体上抠出，滑到边缘时自动被身体轮廓裁剪。
- 表情倾斜只在拉长的眼睛上才看得出来；接近圆形的眼睛倾斜不可见——这就是眼睛必须保持胶囊形（不能做成圆点）的原因。

### 2.2 球面投影（眼睛长在球面上，不是平面贴纸）
- 每只眼画在球面的切平面上，再正交投影。由此免费得到三件事：压缩、倾斜、转到背面消失。
- 靠边的眼睛被压缩：转头到极限时，远眼宽 ≈ **0.69×** 近眼宽，面积 ≈ **0.663×**。在我们实测的温和注视范围（±7% D）内，远眼约 **0.9×** 近眼。
- 实现：眼中心水平偏移 → 球面经度；眼宽 × cos(经度)；经度超过 90° 时眼睛隐藏。
- 宽度压缩只影响宽度，不影响高度（高度只在眨眼时变）。

### 2.3 注视（张望）——待机生命感的主要来源
实测 hero GIF 一个 3.4s 循环（68 帧 @ 20fps），注视点（两眼中心的中点）轨迹：

| 阶段 | 时间 | 注视点 x（相对球心） | 动作 |
|---|---|---|---|
| 中央停留 | 0–0.9s（f1–18） | 0 | 静止 |
| 向左滑行 | 0.9–1.45s（f19–29） | 0 → **-15px（-7% D）** | 指数缓出，先快后慢，步长从 2.5px/帧递减到 0.4px/帧 |
| 左侧停顿 | 1.45–1.95s（f29–38） | -15px | **停 0.5s** |
| 快速扫到右 | 1.95–2.15s（f39–42） | -15px → +2.6px | 0.2s 快速通过中央 |
| 右侧停顿 | 2.15–2.6s（f43–51） | **+10px（+5% D）** | **停 0.45s** |
| 缓慢回中央 | 2.6–3.4s（f52–68） | +10px → 0 | 0.85s，缓慢指数缓出 |

- **注视范围：水平 ±7% D，垂直 ±1% D**（基本只水平动，垂直几乎不动）。grokbot-web 的归一化注视输入钳制在 [-1, 1]，映射到约 ±13.2 × ±8.4 单位，与实测一致。
- **节奏 = 滑行 + 停顿，停顿和滑行同等重要。**滑行 0.4–0.6s（短距离）/ 0.2s（长距离快速通过）/ 0.85s（缓慢回中央）；每处停顿 **0.4–0.9s**。不要连续不停地扫视——没有停顿的注视读起来像"心神不宁"，不是"活着"。
- 注视目标 = 绝对目标（指针跟踪）+ 自动漫游的混合；漫游在混合之后叠加，保证键盘/触屏用户也能看到活的注视；指针主动指挥方向时漫游消失。
- 注视时**身体不动，只有眼睛动**。眼对整体倾斜 ±3px（约 ±1.5% D），方向与注视方向一致（向左看时左眼略高、右眼略低，反之亦然）。
- 注视时两眼中心间距会略微张开：静止 63px（31% D）→ 侧视时 67px（+6%）。这是球面投影的自然结果，不用单独做动画。
- 落地配方（待机）：每 0.9–1.5s 选一个新注视目标（70% 概率水平方向，30% 概率轻微上下）；滑行 0.4–0.6s 指数缓出到达；停顿 0.4–0.9s；再选下一个。注视目标不要超出 ±7% D（水平）/ ±2% D（垂直）。

### 2.4 眨眼
- 实测 hero GIF 一次眨眼（f30–32，位于左侧注视极值点）：**总时长 0.2s**（4 帧 @ 20fps）。眼高 61 → 29 → **12** → 26 → 53 → 61。
  - 闭合 **~0.1s**（61 → 12，两帧），**闭比开快**。
  - 睁开 **~0.15s**（12 → 61，三帧）。
  - 眼高最低点约 12px ≈ 满高的 **20%**（grokbot-web 的 floor 是 4%，即几乎全闭；实测 GIF 的最低点是 20%，两者都认可"不完全归零"的收法）。
- **眨眼节律**：待机每 **2.5–4s** 一次；思考态放慢到 **3.5–7s** 一次；睡眠态不眨眼。眨眼时间表是**预先写好的确定性数据，不是随机定时器**（保证可复现、可测试）。
- 两只眼**同步**眨眼。眨眼时眼宽不变，只有眼高塌缩（scaleY）。
- **眨眼藏变形（最重要的一条机制）：**每次身体形状/表情切换，都藏在一次眨眼里——眼闭 → 形变 → 眼开。强制遮盖眨眼 0.2s。**禁止在眼睛睁着的时候切换表情/形状**，否则读成"瞬移"（实测两帧之间跳 15px）。

## 3. 表情切换

- **状态机，不是关键帧片段。**状态：`sleeping / waking / idle / listening / thinking / searching / working`（生命周期）；反应：`excited / surprised / suspicious / angry / drowsy / happy / curious / confused / bored / proud / shy / sad / laughing / scared / playful / celebrate`；智能体形态：`orbit / radar / progress`；产品生命周期：`spawning / humming / loading / dictating / writing / sending / receiving / uploading / notifying / alerting / dragging / bouncing / powering-down`。共 39 个状态（nasawz/grokbot-web 实测）。
- 每个状态声明一组**表情池**（从 25 个表情里取），引擎在池子里漂移。25 个表情（索引 0–24），每个是两只眼各一个 **48 点闭合环**；切换时在两个 48 点环之间**线性插值**。
  - **thinking 表情池：[8, 16, 14, 17, 5]**（grokbot-web 实测）。思考时眼睛在这 5 个表情之间缓慢漂移。
- **缓动：指数缓出 Cubic(0.645, 0.045, 0.355, 1.0)，y(0.5) = 0.516875。永不超调。**这是 grokbot-web 精确复现的曲线。所有圆球/表情过渡都用它。
- 切换时长：**0.3s**（入场淡入也是 0.3s）。切换时先眨眼（0.2s 遮盖），在眼闭期间完成形变。
- 形状变形（径向轮廓）：每个轮廓在同一 64 个角度采样半径，任意两形状逐点线性插值半径。产品只用圆形，形状变形暂不启用；但机制要保留（以后换形状时不重写）。
- **弹簧参数（只给坚持用弹簧实现的团队）：**要复现"无超调"，必须用**临界阻尼 ζ = 1.0**。ζ = c / (2√k)。
  - 诺玛：**k175 / c26.5**（ω = 13.2 rad/s，ζ = 1.0）。现状 c23（ζ = 0.87，超调 0.4%，可忽略），建议提到 26.5。
  - EVA：**k315 / c35.5**（ω = 17.7 rad/s，ζ = 1.0）。现状 c27（ζ = 0.76，超调 2.5%，略弹），建议把 c 提到 35；1.7× tempo 靠提高 ω（13.2 → 17.7）实现，不是降低阻尼。
- 动画循环**只在变形/眨眼/旋转进行时运行**，待机时不跑循环（省电）。首次绘制不等动画帧（后台标签页切回来也不空白）。

## 4. 状态动画（思考 / 执行 / 等待 / 完成 / 异常）

状态由圆球本身的运动编码（xAI 官方六态：idle / thinking / working / waiting / blocked / done）。工作到来时先"确认"（acknowledge），开始工作时"进入状态"（kicks into gear），等待/受阻时动作再变，完成时安定下来。

| 状态 | 眼睛 | 身体 | 节奏 |
|---|---|---|---|
| **idle 待机** | 注视漫游（§2.3），眨眼 2.5–4s 一次 | 0.5% 微呼吸，中心固定 | 平静、略带好奇 |
| **listening 聆听** | 眼睛放大 5%（eyeScale 1.0 → 1.05），注视锁定输入框方向 | 不动 | 专注、等待输入 |
| **thinking 思考** | 在 thinking 表情池 [8, 16, 14, 17, 5] 之间缓慢漂移；眨眼放慢到 3.5–7s 一次；注视缓慢扫读（像读字一样逐行扫，行尾停一拍） | 呼吸略深（+1%） | 慢、深、不急 |
| **working / searching 执行** | 眼睛睁大/聚焦（eyeScale 1.05–1.1），注视锁定工作对象；EVA 并行时眼睛在多个工作点之间切换 | 进入状态时一次 +2% 均匀缩放脉冲（0.3s 缓出）；EVA 期间带极淡蓝光晕（产品已有） | 快、有劲、不拖沓 |
| **waiting 等待** | 注视放空（视线略微上移/发散），眨眼变慢 | 呼吸放慢 | 松、不催 |
| **blocked 受阻/异常** | 眼睛收窄成警觉形，或显示 leaning "!"（胶囊条 + 水滴点，圆端朝条）；身体轻 shake（左右 3–7px/帧，横向不超过 6px，不出界） | 轻 shake，不做大幅度动作 | 短促、提醒、不吓人 |
| **done 完成** | 眼睛弯成笑弧（happy 表情），完成时眨一下眼 | 一次 +2% 均匀缩放弹出（0.3s 缓出，无超调） | 轻快、收尾干净 |

- **诺玛 → EVA 切换仪式（产品已有，保留）：**拨开开关圆球荡两圈涟漪、窗口呼吸一次泛蓝光、对话落"EVA 模式已开启"、EVA 期间保留极淡蓝光晕。补充一条 grokbot 式的：切换时圆球做一次 **spin（整圈 1200ms）**或眼睛绕球转满一圈（呼应 §1.4 出场），不要只换颜色。
- **tempo（诺玛 vs EVA）：**诺玛 1×（ω = 13.2），EVA 1.7×（ω = 17.7）。tempo 只改速度（ω），不改阻尼（ζ 保持 1.0），不改幅度。EVA 的弹簧/呼吸/眨眼/张望/入场/流式都随之变快，切回自动缓下来。

### 4b. 聊天区内联状态指示器（思考 / 探索 / 起草）——视频款

> 这是**聊天消息区里的独立小指示器**，不是圆球。圆球负责"角色在场"（状态由眼睛编码），指示器负责"正在干什么"（文字可读）。两者同时存在，不互相替代。位置：**聊天消息区里、跟着消息走**（每条智能体消息带自己的工作状态），不是只挂在窗口顶部。

- 形态：小动画图标 + 灰色状态文字。图标约 **16–20px**，文字 **12–13px 灰色**，图标与文字间距 **6–8px**。
- **思考**：三个青色小圆点横排（约 8–10px，青色，第三个略大/略深），**依次跳动**（bounce，相位差 0.12s，周期约 0.6s），配灰色"思考"二字。
- **探索**：中央青色圆点 + **两圈同心圆脉冲环**（由内向外扩散、淡出，周期约 1.2s），配灰色"探索"。
- **起草**：青色竖直笔形标记（带小拖尾，像正在写字），轻微上下写动，配灰色"起草"。
- 状态切换时指示器**交叉淡化 0.2s**，不硬切。指示器只在对应状态时显示；状态结束时落成"已思考 N 秒"（带真实计时）。
- 注意：xAI 明确拒绝了"三个跳动圆点"作为**圆球**的思考状态——但作为聊天区**文字可读的**工作状态指示器，它是视频里的做法，产品里保留这一层。

## 5. 通用过渡（时长与缓动）

### 5.1 核心缓动
- **圆球/表情/注视：指数缓出 Cubic(0.645, 0.045, 0.355, 1.0)**，y(0.5) = 0.516875。永不超调。
- **唯一允许超调的地方：通知小点弹出 +14%**（0.3s）。除此之外全系统禁止超调。

### 5.2 时长表

| 动作 | 时长 | 备注 |
|---|---|---|
| 眨眼 | **0.2s** | 闭 0.1s（快）+ 开 0.15s；两眼同步 |
| 表情/状态切换 | **0.3s** | 先眨眼遮盖（0.2s），眼闭期间形变 |
| 注视滑行（短距离） | **0.4–0.6s** | 指数缓出，先快后慢 |
| 注视快速扫过 | **0.2s** | 长距离通过中央时 |
| 注视回中央 | **0.85s** | 最慢、最缓 |
| 注视停顿 | **0.4–0.9s** | 每处停留，停顿和滑行同等重要 |
| 身体呼吸（待机） | **3.4s/循环** | 吸入 1.4s + 呼出 1.4s + 停顿 0.6s，幅度 0.5% |
| 身体呼吸（活跃） | 同上 | 幅度 +6.9%（hero 实测），仅单次脉冲 |
| 通知小点弹出 | **0.3s** | +14% 超调 |
| Spin 整圈 | **1200ms** | 出场 / EVA 切换 |
| 入场淡入 | **0.3s** | 出场只播 idle |
| 指示器状态切换 | **0.2s** | 交叉淡化 |
| UI 控件（按钮/面板/菜单） | **0.24s** | 产品现有统一值，保留；ease-out |
| 指示器圆点跳动 | **0.6s/周期** | 相位差 0.12s |
| 指示器脉冲环 | **1.2s/周期** | 由内向外扩散淡出 |

### 5.3 弹簧参数（只用于 UI 控件与通知弹出，不用于圆球本体）

| 用途 | 参数 | 说明 |
|---|---|---|
| 诺玛 tempo | k175 / **c26.5**（ζ = 1.0） | ω = 13.2；现状 c23（ζ = 0.87）超调 0.4%，建议提到 26.5 |
| EVA tempo | k315 / **c35.5**（ζ = 1.0） | ω = 17.7，1.7×；现状 c27（ζ = 0.76）超调 2.5%，建议把 c 提到 35 |
| 通知弹出 | +14% 超调（ζ ≈ 0.55，或直接写死 +14% 关键帧） | 全系统唯一允许超调的地方 |
| 按钮按压 | 0.24s + 按压缩放 0.97 | 产品现有，保留 |

### 5.4 性能与可访问性
- 只动 `transform` / `opacity`，60fps；不触发布局。
- 动画循环只在变形/眨眼/旋转进行时运行，待机时不跑。
- `prefers-reduced-motion`：全部动画直达终态，出场动画不播放。
- 眼睛是 mask 洞，滑到边缘自动裁剪，不用额外裁剪代码。

## 6. 禁忌（不要做的事）

1. **不要让身体上下浮动（bob）。**身体中心固定，生命感来自注视 + 眨眼。
2. **不要把身体压成椭圆。**禁止 `scaleX ≠ scaleY`；身体永远是正圆。
3. **不要用带超调的弹簧做圆球/表情过渡**（除通知弹出 +14% 外）。
4. **不要在眼睛睁着的时候切换表情/形状。**必须用 0.2s 眨眼遮盖。
5. **不要给眼睛加高光。**眼睛是纯色药丸/胶囊。
6. **不要用"三个跳动圆点"作为圆球的思考状态。**那是聊天区指示器的事；圆球的思考靠 thinking 表情池。
7. **不要让眼睛离开身体轮廓。**眼睛是 mask 洞，滑到边缘要被裁剪。
8. **不要在出场时用非 idle 状态。**会眼睛跳变 15px，读成瞬移。
9. **不要连续不停地扫视。**没有停顿的注视读起来像心神不宁。
10. **不要给静止的圆球加"漂浮"来凑生命感。**静止时中心稳定到 ±0.003 倍半径；0.5% 呼吸 + 注视 + 眨眼就够了。
