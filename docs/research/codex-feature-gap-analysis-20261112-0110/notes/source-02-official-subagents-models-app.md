# Source 04 — Subagents (official, verified live 2026-11-12)
- URL: https://learn.chatgpt.com/docs/agent-configuration/subagents
- Subagent workflows enabled by default in current releases; activity visible in desktop app, CLI, IDE extension. Spawn only on direct request or AGENTS.md/skill instruction. Main thread = requirements/decisions; subagents return summaries, not raw logs. Read-heavy first (exploration/tests/triage/summarization); careful with write-heavy (conflicts).
- Built-ins: default / worker / explorer. Custom agents: TOML under ~/.codex/agents/ or .codex/agents/, required name/description/developer_instructions; optional model/model_reasoning_effort/model_reasoning_summary/model_verbosity; can disable features (shell_tool, apps, plugins, memories, request_permissions_tool) and skills; inherit parent permissions/provider/MCP; cannot override sandbox/approval/provider/MCP.
- Global [agents]: enabled (default true), max_concurrent_threads_per_session (legacy alias max_threads, default 6 per secondary), default_subagent_model/reasoning_effort, interrupt_message (default true).

- URL: https://learn.chatgpt.com/docs/models (search result; page text via index)
- Astra = most capable/hardest end-to-end; GPT-6.1 Sol = near-Astra, lower cost, recommended for most/complex + long-running (default context 500k tokens in Codex/Work); GPT-6.1 Terra = fast/efficient, writing/visual/computer use; Luna = focused/repeatable/high-volume, most efficient. - Reasoning efforts: low/medium/high/xhigh/max/ultra (per subagents page: ultra deepest when supported; Luna up to Max, not Ultra). Defaults differ per model (Sol low, Luna high, Astra low per secondary; treat as secondhand). plan_mode_reasoning_effort separate override (secondhand, config ref). Fast/Ultrafast service tiers catalog-driven (/fast; Ultrafast Pro $500/eligible Enterprise/Edu, GPT-6.1 Sol/Astra).
