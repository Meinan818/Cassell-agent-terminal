# Official config sources — read 2026-11-12
- https://developers.openai.com/codex/config-reference (3289 lines, read fully 0-3289) — verified live via browser_open
- https://developers.openai.com/codex/config-basic — read fully; precedence: CLI flags/-c > project .codex/config.toml (trusted only, closest wins) > profile $CODEX_HOME/<name>.config.toml > user ~/.codex/config.toml > cloud-managed defaults > system /etc/codex/config.toml (Unix) > built-in defaults.
