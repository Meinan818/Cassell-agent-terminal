# Claude Code Desktop — official docs (verified live 2026-11-12)
URL: https://code.claude.com/docs/en/desktop
Read: 2026-11-12, via browser_open (crawled <1 min before) AND live research browser (tab t1, page rendered, TOC confirms sections: Arrange your workspace, See session details, Switch view modes, Watch background tasks, Manage sessions).
- Code tab in Claude Desktop app; also Chat and Cowork tabs. Each conversation = a session, own chat history + project folder; sidebar lists sessions, run several in parallel.
- Panes: chat, diff, browser, terminal, file, plan, tasks, subagent (+ iOS Simulator macOS). Drag by header, resize by edge, pop out into own window, dock back. Title-bar icon buttons (Terminal, Changes=diff, Browser, Files); Background tasks and Plan panes appear in ⋮ menu once session has something to show. Requires Desktop v1.2581.0+.
- Session details panel (right rail, "session rail"): cards beside chat showing where session runs, what it changed, what it's running, context usage. Hide/show via Hide/Show session rail. Minimized panes sit below its cards.
- View modes (Transcript view dropdown / Ctrl+O cycle): Normal = tool calls collapsed into summaries, full text; Thinking = collapsed tool calls + Claude's thinking (only appears after thinking produced); Verbose = every tool call, file read, intermediate step + thinking. Pre-1.46388.1 also had Summary mode; sessions set to Summary open in Normal after update.
- Diff: click +12 -1 line counts in Changes card of session details panel, or Changes in title bar; file-by-file; hover line + to comment, Cmd/Ctrl+Enter submits all comments; Claude iterates. /code-review findings as Code review card grouped by file, Walk through in diff / Apply fixes. PR in Changes card with CI status, Auto-fix / Merge when ready toggles.
- Manage sessions: + New in sidebar / Cmd+N / Ctrl+N; Ctrl+Tab cycle; Option/Alt+click or right-click Open in > Split view / New window; split pane dimmed non-focused. Worktree toggle per session, stored <project-root>/.claude/worktrees/. Group/sort via hover heading icon; Archived tab via View all; rename via title bar; auto-archive after PR merge/close (setting). OS notification when Code session finishes and you're not viewing it.
- Watch background tasks: tasks pane shows background work in current session: subagents, background shell commands, dynamic workflows. Open via Background tasks in title-bar ⋮ menu once session has background work. Click entry to see output in subagent pane or stop it. Other sessions via sidebar or ask Claude.
- Suggested-task cards: Start starts task in another session, sidebar lists started session under current one; Start all; Options (environment/model/worktree/permissions). Nested sessions (Oct 2026, secondary sources) — children listed under parent, report result back.
- Side chat: Cmd+; / Ctrl+; or /btw; reads main thread context, writes nothing back; not saved to disk.
- Work across sessions: Claude lists/reads/messages other Code-tab sessions (local/SSH/WSL only, 20 most recent, skips archived); incoming message shown as card with sender title + link back.
- Extend: Customize in sidebar manages connectors, skills, plugins in one place. Usage: Context card % in session details panel, open for per-category breakdown; /context prints breakdown; usage ring under prompt box for plan usage.
- Stop: stop button interrupts immediately; typing correction sends without stopping running action (Claude reads it after current action).
- What's NOT in Desktop: Agent teams (CLI only); use dynamic workflows / cross-session messaging instead.
