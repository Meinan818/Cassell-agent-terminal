# Claude Code in VS Code — official docs (index, crawled 2026-11-12)
URL: https://code.claude.com/docs/en/vs-code
- Agent map: when conversation includes subagents, count e.g. "2 agents" at bottom of prompt box; dot shows whether any subagent is working or waiting for permission. Click opens agent map: tree under main agent, each subagent with status, elapsed time, token count. Click a subagent to see its prompt and tool calls, open its read-only transcript, or stop it while running. Requires v2.1.269+. Map also lists other background tasks (background shell commands, monitors) below agents; click row to open task card and stop it. /tasks opens map when no count showing (v2.1.277+). With v2.1.286+, Stop/Esc ends current turn; background agents keep running until they finish or you stop them from map.
- Run in background: click "Run in background" below a tool call (v2.1.287+); Claude stops waiting, continues turn; command/subagent keeps running as background task, notifies Claude when done. /tasks to check/stop.
- Focus view: hides tool calls, tool results, thinking behind expandable rows, leaving prompts + responses; to-do list stays visible. While Claude runs subagents, live progress rows with latest activity appear under the tool-call group that started them (v2.1.269+).
- Thinking: block showing only label e.g. "Thought for 12s" has no text, doesn't open. showThinkingSummaries=true in ~/.claude/settings.json, reload window, then click block or Ctrl+O to expand.
- Usage: /usage opens Account & usage dialog; plan usage bars; attribution tables of usage by skill, subagent, plugin, MCP server; Day/Week toggle; figures approximate, local sessions on this machine only. Sessions list in Activity Bar shows active session totals under Account & usage header (v2.1.277+).
- Checkpoints: hover message > rewind button: Fork conversation from here / Rewind code to here / both.
- Panel placement: drag Claude panel to secondary sidebar (right), primary sidebar (left), or editor area as tab.
- Session history: search/browse by time, AI-generated titles, rename/archive on hover, Archived sessions group, auto-archive after 14 days inactive (v2.1.265+).
