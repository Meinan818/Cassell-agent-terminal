## 3. 产品全貌（每个面做到什么程度算完成）

只写能验证的验收标准，不写"体验好"这种没法测的。

### 3.1 NORMA 办公模式（对标 Claude Cowork）

- **是什么**：办公伙伴，帮路专员处理文字、表格、文档、日程、信息整理。产出是**文档和结论**。
- **验收标准**：
  - 能写文档、整理资料、查信息、理思路；先给结论再给步骤；交付的是能直接用的文件（带可用公式的表格、能直接讲的演示、格式好的文档），不是"怎么做"的教程。
  - 在用户选文件夹之前看不到任何文件；只在授权文件夹里工作（见 3.9）。
  - **五条硬禁，一条都不能破**：不碰代码仓库、不跑终端命令、不做多智能体工程编排、不接 MCP 代码工具与 LSP、不把"写完了"说成"验证过了"。
  - 用户在 NORMA 里说"改这段代码"，不硬做，提示"这是工程活，切到 EVA 我帮你改"，一键切。
  - 默认思考强度 Medium；问候讲今天、讲待办、讲人。

### 3.2 EVA 工程模式（对标 Claude Code）

- **是什么**：工程搭档，帮路专员读代码、改代码、跑验证、管仓库。产出是**可验证的改动**。
- **验收标准**：
  - 每次改动给 diff，确认再落盘；跑构建/测试/lint，输出过滤、失败定位到行；改过的文件没有验证覆盖就不许说完成（交付门）。
  - Plan 模式与 Goal 模式是真实现，不是开关摆设（见 P0-5、P0-6）。
  - **五条硬禁，一条都不能破**：不做办公文档套件、不做闲聊与情感陪伴、不碰用户的日程/邮件/群消息、不做定时后台办公任务、不对业务判断背书。
  - 用户在 EVA 里说"帮我写个周报"，提示"这是办公活，切到 NORMA 我帮你写"，一键切。
  - 默认思考强度 High；ULTRACODE 只在 EVA 里出现，默认关闭，开启时明说成本（"将并行派出多个子代理，token 与耗时都会上升"），小任务自动不触发；NORMA 界面里一个字都不要出现 ULTRACODE。

### 3.3 开机七步

- **是什么**：粒子校徽 → 身份认证门 → 指纹 → 登录表单 → 权限核验环 → ACCESS GRANTED → WELCOME，总时长约 20 秒（故意设计的体验时长，不准压缩）。
- **验收标准**：
  - 七步顺序与约 20 秒时长一字不动；设置里有启动动画开关（默认开、显眼处、持久化）。
  - 全程纯黑夜空（`#000000`），星野七步全程清晰可见，不只校徽段有。
  - 粒子校徽必须由白色粒子构成真正的 3D 校徽（有深度、厚度、旋转/视差），不是二维拼图或照片校徽；汇聚过程本身好看（引力牵引、ease-out 轻柔落位）。
  - 指纹与核验环不是简笔画：指纹是真正的纹路/粒子汇聚效果，核验环有纵深、光晕、质感。
  - 欢迎段的诺玛球有灵动感（呼吸/眨眼/光晕脉动），done 态眼睛是自然优雅的浅弧，不是难看的咧嘴。
  - 每步切换平滑交叉淡化，不硬切；开机结束正常进工作区，无白屏无崩溃。

### 3.4 主界面三栏

- **是什么**：左栏（成员/项目/最近/身份卡）+ 对话区 + 右侧 Inspector，底部输入框与状态条。布局按视觉稿 v1，结构原封不动。
- **验收标准**：
  - 侧栏项目行只显示项目名，任务行只显示标题；不要路径副标题、不要"已完成/运行中"药丸；双击重命名与悬停操作保留。
  - 身份卡是真正的横向名片（约 208×122）：S 印章是优雅衬线 S + 1px 发丝圆环，无实心圆底，不要"血统评级"文字；校徽是白色线条矢量 CrestLine，忠实还原真校徽，不能像简笔画。
  - 用户消息是 Grok 式气泡（极淡 tint、无边框、20px 大圆角、紧凑贴文字）；悬停操作按钮脱离文档流，不能留死空白。
  - 字体 Inter + 思源黑体（都打包进应用）；小字无锯齿、不过细；流式光标是 GPT 式蓝色圆点（8px、`#60a5fa`、呼吸脉冲），不是竖条。
  - 新会话空态：100px 圆球、按时段问候、身份小字、上下文栏、同款输入框；无建议芯片、无"试试："行。
  - 全站无 1px 框线感、无金色、无照片/位图素材；出现/消失/切换一律 150–350ms 平滑过渡；思考动画是 Grok 式变形图标，不用普通转圈糊弄。

### 3.5 右侧 Inspector

- **是什么**：对话之外的第二个工作台。5 个页签：**审查 / 终端 / 文件 / 浏览器 / 插件**（插件页签目前是"未接入"禁用态）。
- **验收标准**：见 P0-11（第 4 节）。一句话验收用例——改文件→看 diff→起服务→跑测试，全程一次不跳系统浏览器、不开外部编辑器、不开外部终端。
- **明确不做的**：标注模式（点元素说话）、Computer Use / Chrome 扩展、Cockpit 式 8 tab 仪表盘、阅读模式、窗格自由拖拽。

### 3.6 设置与 BYOK

- **是什么**：模型走 BYOK，用户自配 API Key；DeepSeek 用得最多，workbuddyapi2 等 OpenAI 兼容反代可接。
- **验收标准**：
  - 选服务商、填 Key、测连通；Key 存本地；加 Key 必须真实保存并真实请求 `/models`。
  - **不许假数据**：从空状态开始；未配 Key 的服务商不能显示假模型、假已连接、假掩码 Key、假时间。
  - 设置里有：启动动画开关（默认开、显眼、持久化）、删除确认两档（"每次都问"默认、"不再询问"，持久化；删根目录永远拒绝不受此档影响）、autoVerify 开关（默认开，能关）。

### 3.7 模型与思考强度

- **是什么**：思考强度 Low / Medium / High / XHigh / Max 五档独立；ULTRACODE 是独立开关（高级工程工作流编排，非模型），只在 EVA 出现。
- **验收标准**：
  - NORMA 默认 Medium，EVA 默认 High；切换模式时默认值跟着换。
  - 菜单只列当前模型生效的档；存量档失效时明说实际按哪一档发送；压缩用的模型 ID 与会话主模型解耦（见 P0-3）。
  - 模型名与档位名不硬编码 Claude/Codex 的名字（BYOK 模型各有自己的档位）。

### 3.9 权限与沙箱

- **是什么**：安全边界。NORMA 是文件夹沙箱，EVA 是整机访问——切换的本质是权限边界不同，不是功能多少。
- **验收标准（已完成部分，`be32800`）**：
  - 未选文件夹前文件工具全拒；选定后锁定工作区；换文件夹重新授权；授权只存当前会话。

1. **P0 11 项全部完成**：按本蓝图第 4 节的验收标准逐项过，每项有 commit 或实测证据；"进行中""未开工"清零。
