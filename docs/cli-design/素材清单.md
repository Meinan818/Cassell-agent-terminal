## 6. 节日（10 套 × 13 帧 = 130 帧）

每套 = 特殊形象 1 + 节日版常驻动作 10 种 + 节日专属特殊动作 2。文件名前缀即节日：`christmas-*`、`newyear-*`、`springfest-*`、`valentine-*`、`easter-*`、`halloween-*`、`midautumn-*`、`birthday-*`、`friday-*`、`weather-*`。

每套 13 帧固定为：`*-hat`（特殊形象）、`*-walk`、`*-blink`、`*-look`、`*-jump`、`*-sleep`、`*-roll`、`*-peek`、`*-dance`、`*-snow`、`*-eat`（节日版常驻动作 10 种）、+ 2 个专属特殊动作：

| 节日 | 专属特殊动作 2 个 | 颜色 |
|---|---|---|
| 圣诞 christmas | `christmas-gift`（拆礼物）、`christmas-lights`（挂彩灯） | 红 + 绿 |
| 新年 newyear | `newyear-confetti`（五彩纸屑）、`newyear-firework`（烟花） | 红 + 白 |
| 春节 springfest | `springfest-envelope`（红包）、`springfest-lantern`（红灯笼） | 红 + 白 |
| 情人节 valentine | `valentine-hearts`（飘爱心）、`valentine-rose`（玫瑰） | 粉 + 红 |
| 复活节 easter | `easter-egg`（彩蛋）、`easter-hop`（兔子跳） | 粉 + 白 |
| 万圣节 halloween | `halloween-candy`（糖果桶）、`halloween-ghost`（小幽灵） | 橙 + 绿 |
| 中秋 midautumn | `midautumn-mooncake`（月饼）、`midautumn-rabbit`（小白兔） | 白 + 棕 |
| 生日 birthday | `birthday-cake`（生日蛋糕）、`birthday-balloon`（气球） | 粉 + 蓝 |
| 周五傍晚 friday | `friday-drink`（饮料杯）、`friday-chill`（葛优躺） | 墨镜造型 |
| 天气联动 weather | `weather-umbrella`（雨伞）、`weather-rain`（雨滴） | 蓝雨帽 |

节日版“接雪花”的掉落物与“吃东西”的食物按节日换：圣诞雪花/曲奇、新年彩纸/红点心、春节红瓣/饺子、情人节爱心/巧克力、复活节彩蛋/彩蛋、万圣节糖果/糖果、中秋月饼/月饼、生日彩纸/蛋糕、周五橙片/橙汁、天气雨滴/热饮。

**周五特殊情况**：周五造型是墨镜，盖住眼睛，所以 `friday-look` 肉眼看和 `friday-hat` 一样、`friday-peek` 和原版 peek 一样、`friday-snow` 眼睛上移会并进墨镜里。这是造型本身的限制，不是画错。

每节日拼图：`contact-sheet-<节日>.png`（13 帧）。另有 `contact-sheet-batch1.png`、`contact-sheet-batch2.png`、`contact-sheet-expressions.png`（12 张表情）。

## 8. 多帧升级（进行中，Muse 负责画帧）

用户已拍板：常驻 10 动作 + 10 个节日版全部改成多帧。帧数标准：走路左右各 4 帧、张望左右各 3 帧、眨眼保持 1 帧、跳 3 帧、睡觉 4 帧、打滚 4 帧、躲猫猫 3 帧、跳舞 4 帧、接雪花 4 帧、吃东西 4 帧。新帧文件名加帧号后缀（例如 `walk-R-A/B/C/D`、`jump-1/2/3`、`christmas-jump-1/2/3`），旧单帧文件保留不动。完成后更新本清单。

## 10. 渲染说明（给 Codex 评估）

- PNG 是 26×18 格像素稿，3 色。终端显示用盲文点阵渲染（13 列 × 约 5 行），帧表直接用像素稿。
- PNG 原稿如何转换为终端显示，由 Codex 评估技术可行性；需要视觉降级时交 Muse 确认效果。
- `--plain` 纯文本模式不画 noya。
