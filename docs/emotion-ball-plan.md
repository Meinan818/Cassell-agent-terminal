## 1. 初代情绪球机制拆解

### 1.1 总体架构：三层 + 适配层，职责干净

| 层 | 文件 | 职责 | 关键点 |
|---|---|---|---|
| 数据层 | `emotions.js` + `rings.js` | 纯数据，零逻辑 | 32 个表情定义 + 25 组眼环几何 + 3 种身体形状 |
| 驱动层 | `engine.js` | rAF 状态机 + 插值 + 调度 | 弹簧、动画原语、眨眼队列、表情池轮换、待机策略 |
| 渲染层 | `ball.js` | 纯渲染，零业务逻辑 | SVG 骨架、球面投影、彩带/撒花/zzz 粒子 |
| 适配层 | `evaball.js` | 配色 + 语义翻译 | 球本体一行没改，只做映射 |
| 文案层 | `i18n.js` | 中英字典 | 与动画无关，可忽略 |

宿主只依赖驱动层一个入口：`EmotionBall.create(el, opts)` → `engine.setEmotion(id)` / `engine.handleAIMessage({emotionId, tips})`。这个分层值得全盘照搬。

### 1.2 表情数据（`emotions.js`）：32 种，四组，ID 即契约

分组规则（十位 = 分组前缀，组间空号预留扩展，**编号不可重排**）：

- **00–09 生命周期（8 个）**：00 睡眠、01 唤醒、02 待机放空、03 好奇、04 发呆、05 加载苏醒、06 休眠、07 抖动唤醒
- **10–29 情绪反应（12 个）**：10 开心、11 疑惑、12 失落、13 惊讶、14 害羞、15 疲惫、16 专注、17 慌张、18 无奈、19 满意、20 困惑、21 生气
- **30–49 代理工作状态（12 个）**：30 思考中、31 接收任务、32 处理中忙碌、33 任务完成、34 出错、35 等待输入、36 联网加载、37 复述回忆、38 拒绝/受限、39 输出回复、40 检索资料、41 停止终止
- **50+ 自定义**：空着，预留

每个表情是一份声明式配置，字段（`emotions.js` 头部注释 + `engine.js normalize()`）：

| 字段 | 含义 | 典型值 |
|---|---|---|
| `pool` | 眼环索引池（25 组轮廓眼环里取） | 思考中 `[8,16,14,17,5]`；检索 `[15,9,3,20,12,18]` |
| `poolMs` | 池内轮换间隔 [min, max] ms | 检索 `[1000,1800]`（高速），待机 `[9000,16000]` |
| `poolSpeed` | 形变弹簧频率 | 检索/兴奋类 10，默认 6 |
| `blinkMs` | 眨眼间隔 [min, max] ms，`null` = 不眨眼 | 睡眠/停止类 `null` |
| `openness` | 常驻开合度 | 睡眠 0.08、疲惫 0.55、拒绝 0.6 |
| `transition` | 切入过渡时长 ms | 惊讶 180（快）、休眠 1200（慢） |
| `antics` | 待机随机小动作（自旋/弹跳） | 待机、开心、满意为 `true` |
| `body` | 身体基态：`{x, y, scale, rotate, color, breathe, zzz, orbit, ribbons, confetti}` | 思考中 `orbit: 1`；完成 `ribbons: 1, confetti: 0.95` |
| `eyes` | 眼睛基态：`both` / `left` / `right` 各 `{x, y, scaleX, scaleY, rotate, open, lookX, lookY}` | 疑惑：左眼放大 1.1、右眼缩小 0.9 |
| `anims` | 持续动画列表：`{target, prop, type, amp, period, phase}` | 见 1.3 |
| `sequence` | 关键帧序列：`{frames: [{at, eyes, body}…], settle}` | `settle: 'base'` 回落基础姿态 / `'hold'` 定格末帧 / `{next}` 播完切下一个表情（唤醒 01 → 待机 02） |
| `gaze` | 是否接受注视（`false` = 睡眠/停止类不跟视线） | 睡眠、休眠、停止为 `false` |
| `en` | 英文文案 `{name, desc}`，界面双语用，引擎不消费 | — |

**几何数据（`rings.js`）**：25 组表情眼环，每组 `[左眼环, 右眼环]`，每只眼一个 **48 点闭合轮廓**；另有 3 种身体形状（blob 圆胖 / wedge 三角 / gem 菱形）+ 脸部拟合参数 `{x, y, sx, sy, eye}`。坐标系 viewBox `-15 -15 259 259`，头部中心 `HEAD_C = 114.2705`，`EYE_HALF = 21`。

### 1.3 状态机与插值（`engine.js`）：rAF + 弹簧 + 动画原语

**核心循环**：全局共享 rAF ticker（多实例单循环，集合清空时自动停表，下次 `add` 重新拉起）。每帧 `_tick()` → `_compose()` 合成姿态 → `ball.applyPose(pose)`。

**`_compose()` 合成管线（每帧顺序，`engine.js` `_compose`）**：

```
base 姿态
  → sequence 关键帧采样（播完按 settle 处理）
  → 内置呼吸（相位用绝对时间，切换表情不跳变；body.scale += br·sin，body.y += br·55·sin(phase+0.6)）
  → anims 动画原语叠加
  → 表情池轮换（到点随机跳池内另一个眼环）
  → 眨眼调度（到点把关键帧入队）
  → 待机小动作（9–18s 随机自旋/弹跳/眨眼）
  → 弹簧整步（子步 1/120 保稳定）：形变 / 开合 / 自旋
  → 弹跳位移（4 段递减抛物线）
  → 眼环逐点插值（形变中）或复用目标引用（静止后跳过重建）
  → 注视平滑（指数平滑）+ 常驻眼神微漂移（每只眼相位错开）
  → 开合度 = 配置基础值 × 眨眼弹簧
  → 表情切换过渡插值（easeInOutCubic，ring / yaw 等逐帧动态量回填，避免过渡期冻结）
```

**弹簧（`engine.js` `springStep`）**：临界阻尼弹簧步进，子步 1/120 保证数值稳定，非法值自动回落目标值。三处弹簧：

| 弹簧 | 频率 | 阻尼比 | 用途 |
|---|---|---|---|
| 眼环形变 `_ringSpring` | 7（切换时 8，兴奋类 10） | ζ = 1.0 | 两个 48 点环逐点插值的进度 0→1 |
| 眨眼开合 `_open` | 26 | ζ = 1.0 | 眼睛开合度，可过冲到 1.08 |
| 自旋 `_spin` | 6.2 | ζ = 1.0 | 整圈自旋，追整数圈目标 |

**动画原语（`ANIM_TYPES`，6 种，全部是纯函数 `(a, t, eng) → 数值`）**：

| 类型 | 数学 | 用途 |
|---|---|---|
| `sine` | `amp·sin(2πt/period + phase)` | 漂移 / 呼吸 / 扫视 |
| `pulse` | `amp·0.5·(1−cos(2πt/period))` | 节奏缩放，0→amp 平滑往复 |
| `jitter` | 3 正弦伪噪声 `/3·amp`，可选 `decay` 毫秒内衰减到 0 | 慌张、颤抖、抖动唤醒 |
| `scan` | 三角波 `-1→1→-1` | 检索时目光快速来回扫动 |
| `glance` | `amp·tanh(2.8·sin(phase))` | **张望：平滑方波，在 ±amp 两端各停留片刻再换边**（左看看、右看看） |
| `blink` | 周期内前 `dur` 毫秒闭合再睁开，相位叠加实例随机种子（多实例不同步眨眼） | 左右眼轮流眨（联网加载） |

**眨眼（`_blinkNow` 关键帧队列）**：合上到 0.05 → 停 70ms → 睁到 **1.08 过冲** → 300ms 落回 1；14% 概率追加第二次连眨。**切换表情瞬间先眨一次眼**（睡眠/停止类除外）——这就是"眨眼遮盖形变"的机制，`setEmotion()` 里写死的。

**表情池轮换**：`poolMs` 间隔到点，随机跳到池内另一个眼环（`_setExpr`：把当前插值冻结为新起点，弹簧从 0 重新弹向 1）。池子让"思考中"这类长状态一直有细微变化，而不是一张静止的脸。

**待机小动作（antics）**：9–18s 随机一次，45% 自旋、35% 弹跳、20% 眨眼。弹跳是 4 段递减抛物线（高度 48/28/14/6，时长 0.5/0.382/0.27/0.177s）。

**注视**：`setGaze(nx, ny)` 钳制到横向 ±24、纵向 ±15（viewBox 坐标）；每帧指数平滑 `k = 1 − exp(−5.66·dt)`（60fps 下每帧收敛约 9%）；再叠加**常驻眼神微漂移**——每只眼相位错开的正弦（左眼 `1.4·sin(0.42w) + 0.5·sin(1.0w)`，右眼相位 +1/+2），保证永不完全静止。

**待机策略（`_checkIdle`）**：60s 无活动 → 待机 `02`；180s 无活动 → 睡眠 `00`。`resetIdle()` 在用户交互时调用。

**兜底**：未知表情 ID → 警告 + `error` 事件 + 回退到待机 `02`；`handleAIMessage` 接受 `{emotionId, tips}` 对象或 JSON 字符串，解析失败同样回退。

### 1.4 球面投影与自旋隐藏（`ball.js` `setEye`，机制核心）

渲染层用 SVG，但投影数学与渲染技术无关，可以原样搬到 React 的 div 上：

1. **轮廓采样**：身体轮廓按每 2px 一行采样 `[minX, maxX]`（`silRows`），供眼睛贴合任意身体轮廓。咱们的身体是**正圆**，这一步可以简化为闭式公式（见 3.2）。
2. **纵向**：脸部拟合映射 + 轮廓钳制（`ey0` 钳制在轮廓上下界内）——眼睛永远出不了身体。
3. **横向——经度换算 + 余弦压缩 + 背面隐藏**：
   - 眼睛横向偏移换算成经度：`theta = clamp(ox / hw, −1.15, 1.15)`
   - 加上自旋偏航角：`total = theta + yaw`
   - **`cos(total) ≤ 0.02 时眼睛隐藏（`display: none`）**——自旋到背面自动消失，转回来自动出现
   - 屏幕 x 位置：`ex = cx0 + hw·sin(total)·0.985`（正弦投影，不是线性平移）
   - 宽度压缩：`scaleX = sxBase · cos(total)`（靠边的眼睛被压窄）
   - 纬度因子：`fy = sqrt(1 − dyN²·0.22)`，眼睛离中心越远（上下），高度略压
4. **缩放锚点用当前环自身质心**（不是默认质心）——眼环位置烘焙在数据里（如检索环偏向一侧），绕默认质心缩放会把位置偏差放大、导致眼睛飞出身体。
5. **d 更新跳过**：engine 传入插值后的环，引用不变则跳过 path 重建（性能优化）。

实测对照（grokbot 规范 §2.2）：转头到极限时远眼宽 ≈ 0.69× 近眼宽，温和注视范围（±7% D）内远眼约 0.9× 近眼——与 `cos` 压缩一致。

### 1.5 彩带 / 撒花 / zzz：触发条件与实现

| 效果 | 触发 | 实现（`ball.js`） |
|---|---|---|
| **自旋甩带** | 自旋角速度 `\|vel\| ≥ 0.9` 时开始甩，`≥ 5` 时按 55–105ms 错峰生成拖尾，最多 8 条 | 3D 轨道拖尾：独立 5-stop 色相漂移渐变 + 头宽尾细轮廓 + 圆头封口；按 z 正负拆成前/后两段 path；减速后 0.5s 回缩（smoothstep 弧长收窄） |
| **常驻环带** | 状态 `body.orbit > 0`（只有"思考中" 30 用） | 低倾角水平轨道匀速环绕，最多 2 条，每 700ms 补给一条；状态结束时回缩消失 |
| **撒花** | 进入表情时 `body.confetti > 0`（只有"任务完成" 33 用，0.95） | 一次性物理粒子：初速 170–360，速度衰减 `0.94^60dt`，微重力 40/s，18% 金色五角星、30% 圆点、其余小方块；寿命 0.45–0.85s，上限 60 粒 |
| **zzz** | 状态 `body.zzz > 0`（只有"睡眠" 00 用） | 3 枚字母错峰沿右上漂浮，先淡入后淡出，字号 12→23，旋转 −10°→+4° |

### 1.6 适配层（`evaball.js`，139 行）：球本体一行没改

只做两件事，干净得可以当模板：

1. **配色映射**：原版奶油白系 → EVA 青。判定"奶油色" = RGB 差值 ≤ 30 且亮度 ≥ 0.5；换色 = 保亮度、换色相（色相 189°、饱和度 0.6，亮度压在 0.42–0.72 之间，免得在深色界面上晃眼）。出错红、腮红等非奶油色原样保留。实现方式：种子在 `engine.js` 加载时已被拷进注册表，改 `EMOTION_SEED` 已太晚——直接把注册表里的 `raw` 深拷一份、换色、重新注册（`register` 幂等，重复调用不会改两次）；没写 `body.color` 的表情显式补上默认体色。
2. **语义映射**：`EMOTION` 表把 EVA 运行状态翻译成表情 ID（30–49 组就是为它预留的"代理工作状态"）：
   ```
   loading:'05'  idle:'02'     armed:'35'    listening:'16'
   thinking:'30' tool:'40'     speaking:'39' done:'33'
   awaiting:'11' error:'34'    denied:'38'   stopped:'41'
   ```
   `setBallEmotion()` 会跳过重复设置（`container.dataset.emotion` 比对）；`pulseBall(engine, 'bounce'|'spin')` 对外暴露弹跳/自旋。
3. **驱动方（`voice.js` `setState`）**：状态一切换就调 `setBallEmotion`，同时更新状态徽章文案（"喊一声「诺玛」就能指挥" / "我在，说吧" / "正在识别…" 等）。

### 1.7 初代的短板（"更好"的突破口）

1. **眼环是重型手写资产**：25 组 × 48 点 = 2400 个坐标点，纯手写 SVG 数据；换一个眼睛形状要重画 48 个点。咱们的药丸眼只需要 4 个数字（scaleX/scaleY/rotate/offset），轻两个数量级。
2. **彩带撒花太派对**：彩虹色相漂移 + 金色五角星，是玩具感，不是工作终端的气质；grokbot 规范也只要单色、克制。
3. **32 种里近一半与工作无关**：害羞、失落、生气、慌张……在一个 agent 终端里永远到不了这些状态，是死表情。表情数量 ≠ 生命感。
4. **注视是鼠标驱动**：`setGaze` 靠指针位置；没有指针（键盘/触屏/没动鼠标）时，生命感只剩正弦微漂移。grokbot 的注视是**有停顿的漫游时刻表**（滑行 + 停顿），不依赖指针。
5. **眨眼是随机定时器**：`blinkMs` 区间内随机，没有确定性时刻表，不可复现、不可测试。
6. **待机小动作太闹**：9–18s 随机自旋/弹跳，在工作界面里会抢注意力；grokbot 的待机生命感只来自注视 + 眨眼。
7. **没有多智能体状态**：12 个代理状态全是单智能体视角，没有"并行"这个概念；EVA 的并行编排在它那里没有对应的表情。
8. **rAF 常驻**：只要 `active` 就每帧跑；grokbot 规范要求"动画循环只在变形/眨眼/旋转进行时运行，待机时不跑"。

## 2. 现在咱们的球缺什么（对照表）

`Mark.tsx` 现状：6 个状态（`idle / listening / thinking / working / done / waiting`），药丸眼 20%×30% D、上半部，诺玛墨色 / EVA 蓝色 / EVA 白眼，CSS 呼吸 3.4s，眨眼靠 `setTimeout` 随机定时器。

| 机制 | 初代有 | 咱们现在 | 缺口 |
|---|---|---|---|
| 表情数据表 | 32 种声明式配置（pool/blink/openness/anims/sequence） | 6 个状态，行为硬编码在 `if (state === …)` 里 | **没有数据层**：加一个表情要改组件逻辑 |
| 眼睛形变 | 25 组 48 点眼环逐点插值，池内轮换 | 只有 `scaleY` 三档（思考 0.55 / 工作 0.8 / 聆听 1.1）+ 完成时换笑弧 | 没有表情池、没有逐点/参数化形变、没有轮换 |
| 球面投影 | 经度换算 + `cos` 压缩 + 背面自动隐藏 | 眼睛只做 `translateX(gaze·size·0.055)` 线性平移 | **没有投影**：眼睛是平面贴纸，不会压窄、不会转到背面消失 |
| 自旋 | 弹簧整圈自旋（6.2，ζ=1），角速度达阈值甩彩带 | 没有自旋 | 没有出场/切换用的整圈 spin |
| 眨眼 | 关键帧队列（合→停 70ms→1.08 过冲→300ms 落回），14% 连眨，切换时先眨眼遮盖 | `setTimeout` 随机（2600–5800ms），160ms 一次性闭到 0.08，无过冲、无连眨、无遮盖 | 眨眼不遮盖表情切换（睁眼换脸 = 瞬移感） |
| 注视 | 指数平滑 + 每只眼相位错开的微漂移 + `glance` 平滑方波（两端停留） | 只有外部 `gaze` prop，无自主漫游、无停顿、无微漂移 | 待机时眼睛是死的（除非父组件传 gaze） |
| 身体动作 | 呼吸（绝对时间相位）+ 弹跳（4 段抛物线）+ 倾斜（每表情 `rotate`，如疑惑 −8°、无奈 10°） | CSS 呼吸 3.4s + 思考时 `rotate(−6deg)` + gaze 倾斜 `gaze·4deg` | 没有倾身/摇摆的时刻表，没有入场脉冲，没有眨眼软沉 |
| 状态切换 | `transition` 插值（easeInOutCubic）+ 眨眼遮盖 + 眼环弹簧 | CSS `transition: transform 180ms` 硬切 | 切换无统一缓动、无遮盖 |
| 特效 | 自旋甩带 / 常驻环带（思考）/ 撒花（完成）/ zzz（睡眠） | 完成时只有笑弧 | 没有"思考中"的持续视觉锚点，没有完成时的收尾信号 |
| 待机策略 | 60s → 待机，180s → 睡眠 | 无 | 长时间不用没有任何变化 |
| 适配层 | `evaball.js`：配色与语义分离，球本体不知业务 | `Mark` 直接收 `eva` / `state` / `fast`，配色与状态混在组件里 | 加状态、换配色都要动组件 |
| 兜底 | 未知 ID 回退待机 + error 事件 | 无 | 非法状态会静默显示错误形态 |
| 弹簧参数 | 临界阻尼 ζ=1.0（三处弹簧），子步 1/120 | 只有 CSS `cubic-bezier(0.34, 1.56, 0.64, 1)`（带超调，不符合规范） | 弹簧参数未按规范校准（诺玛应 k175/c26.5，EVA 应 k315/c35.5） |
| 错误/受阻状态 | 出错 34（红白闪动定格警示红）、拒绝 38（摇头序列） | 无（只有 6 态，error/blocked 没有对应表情） | 出错、等审批、被拒绝时球没有任何表示 |
| EVA 并行 | 无 | 无（只有 `fast` 让眨眼变快） | 并行工作时球和单智能体看起来一样 |

另外，`App.tsx` 的接线现状：`running ? "working" : markState`；`done` 后 2600ms 回 `idle`；消息气泡里的 Mark 只有 `streaming ? "working" : "idle"`。引擎事件（`agent-thinking` / `agent-tool` / `agent-tool-result` / 真实 token）没有一路通到球的状态——球不知道现在是在思考、读文件还是跑命令。

## 3. 「比它更好」的具体做法

### 3.1 表情种类与状态映射：14 个工作状态，一个都不少、一个都不多

原则：**每个表情必须对应一个真实到达的 agent 生命周期时刻**；初代 32 种里 12 个情绪反应（害羞/失落/生气…）在工作终端里到不了，全部砍掉；省下的预算投给真正缺的三个：**检索、并行、受阻**。

| # | 状态 | 触发时刻 | 眼睛 | 身体 | 节律 |
|---|---|---|---|---|---|
| 1 | `idle` 待机 | 无任务 | 注视漫游（滑行 + 停顿，见 3.3） | 均匀缩放呼吸 ±0.5%，3.4s 循环 | 眨眼 2.5–4s 一次 |
| 2 | `listening` 聆听 | 用户正在输入 / 语音收音 | 放大 5%（1.05），注视锁定输入框方向 | 不动 | 眨眼 3–5s 一次 |
| 3 | `receiving` 收到任务 | 消息刚发送，引擎已接单 | 快速眨一下 + 放大到 1.12（点头确认），0.7s 内回落 | 一次 −3px 轻沉后回弹 | 一次性关键帧序列（`settle: 'base'`） |
| 4 | `thinking` 思考 | 模型正在推理（`agent-thinking`） | **思考池漂移**：5 个药丸眼姿态缓慢轮换（见下）；注视缓慢扫读（行尾停一拍） | 呼吸略深（+1%）；头顶一圈**单色细环带**缓慢环绕（见 3.5） | 眨眼放慢到 3.5–7s 一次 |
| 5 | `searching` 检索 | 读文件 / 搜资料（`agent-tool` 读类工具） | 眼睛微聚（向内收 4%），注视左右快扫（三角波，周期 0.7s） | 不动 | 眨眼 1.6–4s 一次 |
| 6 | `working` 执行 | 写文件 / 跑命令（`agent-tool` 写类工具） | 睁大/聚焦（1.05–1.1），注视锁定工作对象 | 入场时一次 **+2% 均匀缩放脉冲**（0.3s 缓出，不循环） | 眨眼 2.8–5.5s 一次 |
| 7 | `parallel` EVA 并行 | ultracode 开启且多路子智能体在跑 | **眼睛在 2–3 个工作点之间跳**：每个点停留 0.8–1.5s 再跳下一个（不是连续扫视）；每路返回时对应侧的眼睛轻眨一下 | 保留极淡蓝光晕（已有）；入场一次 spin（1200ms，见 3.2） | tempo 1.7×（眨眼/张望/呼吸全部按 EVA 参数走） |
| 8 | `replying` 输出回复 | 正在流式输出（`agent-delta`） | 随输出节奏轻微缩放（脉冲 0.68s 周期，幅度 0.1） | 轻微上下起伏与输出同步（幅度 1.2px，周期 0.68s） | 不主动眨眼（等输出间隙） |
| 9 | `waiting` 等待 | 等用户输入 / 等审批结果 | 注视放空（视线略微上移/发散） | 呼吸放慢（周期拉长到 5s） | 眨眼变慢（4–8s 一次） |
| 10 | `blocked` 受阻/等审批 | 审批弹窗弹出 / 工具被拒 | 眼睛收窄成警觉形（scaleY 0.75 + 微聚），或显示 leaning "!"（胶囊条 + 水滴点） | **轻 shake**：左右 3–6px，横向不超过 6px，不出界，0.5s 内收住 | 不眨眼（保持警觉） |
| 11 | `done` 完成 | 任务完成（`AgentResult.success`） | 弯成笑弧（已有）+ 完成时眨一下眼 | 一次 **+2% 均匀缩放弹出**（0.3s 缓出，无超调）+ 2600ms 后回 `idle`（已有） | 一次性 |
| 12 | `error` 出错 | 引擎报错 / 工具失败 | 圆睁（scale 1.14）+ 双眼一高一低（左 −3px、右 +4px，带 ±6°/8° 微倾） | 轻 shake 后定住；**不改身体颜色**（墨色/蓝色是身份色，不拿红色刷脸——比初代的"脸色涨红"更克制） | 定格 1.5s 后回 `idle` |
| 13 | `stopped` 停止 | 用户点停止 / 任务取消 | 闭合眼环：慢慢收小到半闭（scale 0.6、open 0.35）后定格 | 轻微下沉（+3px）+ 缩小到 0.97 | 不眨眼，定格 |
| 14 | `loading` 加载/启动 | 开场 / 引擎初始化 | 双眼缓慢交替亮起（左眼眨、右眼眨，间隔 800ms，像逐项初始化） | 不动 | 播完切 `idle`（`sequence.settle: {next: 'idle'}`） |

**思考池（替代初代的 48 点眼环池）**：5 个参数化药丸眼姿态，轮换间隔 2–3.6s，弹簧频率 6：

| 池位 | 姿态（相对基态） | 读感 |
|---|---|---|
| P0 平静 | 基态 | 沉稳 |
| P1 扫读 | lookX ±9，scaleY 0.95 | 在读 |
| P2 斜视 | 左眼 rotate −6°、右眼 rotate +6°，lookY −4 | 在想 |
| P3 圆睁 | scale 1.12 | 灵光一闪 |
| P4 微聚 | 双眼向内收 3%，scaleY 1.05 | 聚焦 |

**模式 × 状态正交**：NORMA / EVA 不是两套表情，而是**同一套状态 × 两套 tempo**（诺玛 1×，EVA 1.7×）+ 两套配色。ultracode 开关只决定 `working` 是否升级为 `parallel`，不新增表情、不改思考强度（三分法已定：模式 / 思考强度 / ultracode 各自独立）。

**比初代好的点**：14 个状态全部可达（初代 32 种里 12 个情绪是死表情）；`parallel` / `blocked` / `searching` 是初代完全没有的；`error` 不用"脸色涨红"这种玩具化表达；`receiving` 的"点头确认"让发送有回音（现在点发送后球没有任何确认）。

### 3.2 球面投影与自旋隐藏：闭式公式，比初代更顺滑

初代的投影要先采样身体轮廓（因为它有 blob/wedge/gem 三种身体）。咱们的身体是**正圆**，整个投影退化成两行闭式公式——更简单、更精确、没有采样误差：

```
设球半径 R，眼睛基态横向偏移 ox（相对球心），自旋偏航角 yaw（弧度）：
  经度 total = asin(clamp(ox / R, -1, 1)) + yaw
  屏幕 x = R · sin(total)          ← 正弦投影，不是线性平移
  宽度压缩 scaleX = cos(total)     ← 靠边的眼睛被压窄
  背面隐藏：cos(total) ≤ 0.02 时 display: none
  纬度因子 scaleY *= sqrt(1 − (dy/R)² · 0.22)   ← 照搬初代的 fy 公式
```

**React 落地（`Mark.tsx` 内，只动 transform，不动布局）**：

- 每只眼一个 `div`（药丸），`transform: translateX(R·sin(total)) scale(cos(total), fy·scaleY) rotate(tilt)`。`translateX` 用正弦值代替现在的线性 `gaze·size·0.055`——注视越偏，眼睛移动越慢（正弦在边缘变平），这正是"长在球面上"的感觉。
- **眼对倾斜**：注视时眼对整体倾斜 ±3px（向左看时左眼略高、右眼略低，反之亦然），方向与注视一致（规范 §2.3）。
- **间距张开**：侧视时两眼中心间距自然张开 +6%——这是正弦投影的自然结果（近眼 sin 变化快、远眼慢），**不用单独做动画**。
- **自旋（spin）**：`yaw` 从 0 → ±2π，1200ms，临界阻尼弹簧（k175/c26.5 诺玛，k315/c35.5 EVA）或 Cubic 缓出；眼睛转到背面时按 `cos ≤ 0.02` 自动隐藏、转回来自动出现——和初代完全相同的判定阈值。用途：出场、EVA 模式切换（替代"只换颜色"）。
- **出场**：眼睛绕球转满一圈再滑入位置（规范 §1.4），只播 `idle`。
- **小尺寸放大**：32–48px 的小球按比例放大眼睛占比（照搬初代的 `_eyeScale`），保证小尺寸下仍可读。

**比初代顺滑的三处**：
1. 初代的 `theta` 钳制在 ±1.15 弧度（约 66°），眼睛到不了真正的球体边缘；咱们的 `asin` 允许到 ±90°，眼睛可以滑到轮廓线才消失，更符合"长在球面上"。
2. 初代的眼睛位置是"质心 + 偏移"两段式，缩放锚点要特殊处理；咱们的药丸眼质心就是几何中心，锚点问题不存在。
3. 初代的自旋是弹簧追整数圈，角速度靠数值微分估算（`dYaw/dt`，有 `> 1.2` 的钳制兜底）；咱们直接用弹簧的解析速度 `v` 做甩带触发判断，不用微分，没有噪声。

### 3.3 状态切换的插值与弹簧参数：cubic 管离散切换，弹簧管连续运动

**分工规则（比初代更干净）**：

| 运动类型 | 机制 | 参数 |
|---|---|---|
| 离散切换（换表情、换状态） | Cubic(0.645, 0.045, 0.355, 1.0) 指数缓出，**永不超调** | 0.3s；切换前先眨眼 0.2s 遮盖（眼闭期间完成形变） |
| 注视滑行（短距离） | 同上 cubic | 0.4–0.6s，指数缓出，先快后慢 |
| 注视快速扫过（长距离通过中央） | 同上 cubic | 0.2s |
| 注视回中央 | 同上 cubic | 0.85s（最慢、最缓） |
| 眨眼 | 关键帧时刻表（见下），不是弹簧 | 总 0.2s：闭 0.1s（快）→ 开 0.15s；眼高最低点为满高的 20%（GIF 实测），两眼同步 |
| 连续运动（呼吸、微漂移、spin 收尾） | 临界阻尼弹簧 ζ = 1.0，子步 1/120（照搬初代的 `springStep`） | 诺玛 k175/c26.5（ω=13.2），EVA k315/c35.5（ω=17.7，1.7× tempo 靠提高 ω，不是降低阻尼） |
| UI 控件（按钮/面板/菜单） | 现有统一值，保留 | 0.24s ease-out |

**眨眼时刻表（确定性数据，不是随机定时器）**：

- 待机：每 2.5–4s 一次；思考态：3.5–7s 一次；睡眠/停止/受阻：不眨眼。
- 时刻表预先写好（可复现、可测试），不是 `setTimeout(Math.random())`。
- 关键帧：`t=0` 眼高 1.0 → `t=100ms` 眼高 0.2 → `t=150ms` 开始睁开 → `t=250ms` 回到 1.0；**闭比开快**（GIF 实测：61→12 用两帧，12→61 用三帧）。
- **眨眼藏变形（铁律）**：每次换表情，先眨眼（0.2s），眼闭期间完成形变，眼开时已是新表情。禁止在眼睛睁着的时候切换表情/形状（否则读成"瞬移"，实测两帧之间跳 15px）。
- 细节：初代的眨眼睁开时过冲到 1.08——保留这个微过冲（只作用于**眼睛**开合度，不作用于身体，0.15s 内收回），它让眨眼读起来"活"而不是"机械"；身体缩放永不过冲。

**注视漫游时刻表（替代初代的鼠标驱动 + 正弦微漂移）**：

```
每 0.9–1.5s 选一个新注视目标（70% 概率水平方向，30% 概率轻微上下）
  → 滑行 0.4–0.6s 指数缓出到达
  → 停顿 0.4–0.9s（停顿和滑行同等重要）
  → 再选下一个
范围：水平 ±7% D，垂直 ±2% D（基本只水平动）
注视时眼对倾斜 ±3px，方向与注视方向一致
指针主动指挥方向时漫游消失（混合：绝对目标 + 自动漫游，漫游在混合之后叠加）
```

**身体动作（与规范的冲突处理，明确写出来）**：

规范 §1 禁止身体上下浮动（bob）与宽高比挤压，但用户 2026-11-13 00:58 的最新反馈要求"球需要更完整的动画与生命感，不只是眼睛动"，artifact 版已按 4.6s 慢周期做了全身起伏/倾身/摇摆。两者的调和方案——**只允许均匀缩放 + 整体旋转，永不允许垂直位移与宽高比变形**：

| 动作 | 做法 | 禁止 |
|---|---|---|
| 呼吸 | **均匀缩放**（scaleX = scaleY），待机 ±0.5%，4.6s 慢周期（吸入→停顿→呼出） | 禁止 scaleX ≠ scaleY |
| 倾身 | **整体旋转**（rotate），随视线方向 ±3–6°，如疑惑 −8°、无奈 +10°（照搬初代每表情的 `rotate`） | 禁止身体变形 |
| 摇摆 | 缓慢的旋转摆动（周期 4.6s，幅度 ±2°）+ 注视驱动的倾身，不是位置摇摆 | 禁止中心上下浮动（bob） |
| 眨眼软沉 | 眨眼瞬间身体**均匀**缩小 1.5% 再弹回（果冻式软沉，但保持正圆） | 禁止压成椭圆 |
| 入场/完成脉冲 | 单次 +2%～+6.9% 均匀缩放，0.3s 缓出，不循环 | 禁止循环脉冲 |

### 3.4 适配层设计：球本体与状态翻译分离，加表情不用动本体

照搬 `evaball.js` 的两件事结构，落到 React 里是两个独立模块：

```
src/components/mark/
  expressions.ts   # 数据层：表情表（照搬 emotions.js 的字段，见 3.1）
  useBallEngine.ts # 驱动层：rAF + 弹簧 + 眨眼/注视调度 + 姿态合成（照搬 engine.js）
  Mark.tsx         # 渲染层：只收 {pose, palette}，不知道 agent、不知道 EVA
  ballAdapter.ts   # 适配层：配色 + 语义翻译（照搬 evaball.js）
```

**`ballAdapter.ts` 的两件事**：

1. **配色**：`(mode, theme) → palette`。诺玛墨色 / EVA 蓝色（浅色 #2563EB / 深色 #7DA6FF）、EVA 眼睛白色；亮暗双主题各一套渐变参数。球本体只收 `palette`，不知道"诺玛"和"EVA"这两个词。
2. **语义**：`(agentEvent) → ballState`。引擎事件 → 球状态的映射表（对照初代的 `EMOTION` 表）：
   ```
   runStart        → 'receiving'   (点头确认)
   agent-thinking  → 'thinking'
   agent-tool(read类: read/list) → 'searching'
   agent-tool(写类: write/run)  → 'working'
   agent-tool-result → 保持当前态（不闪）
   agent-delta     → 'replying'
   runDone(success) → 'done' → 2600ms 后 'idle'
   runDone(error)  → 'error' → 1500ms 后 'idle'
   approvalPending → 'blocked'
   userStopped     → 'stopped'
   ultracode on + 多路并行 → 'working' 升级为 'parallel'
   ```
   映射表是唯一知道"引擎事件"的地方；`Mark` 只认识 14 个球状态。

**加表情的流程（验证"不用动本体"的标准）**：在 `expressions.ts` 加一条配置 + 在 `ballAdapter.ts` 的映射表加一行 → 完成。`Mark.tsx`、`useBallEngine.ts` 一行不改。**兜底**：未知状态 → 回退 `idle` + `console.warn`（照搬初代的 fallback 机制）。

**性能（照搬初代 + 规范）**：
- 全局共享 rAF ticker（多实例单循环，集合清空自动停表）——侧栏小球、消息气泡小球、主球共用一个循环。
- 动画循环只在变形/眨眼/旋转进行时运行；待机时不跑循环（呼吸用 CSS `animation`，合成器层，零 JS）。
- 只动 `transform` / `opacity`，60fps，不触发布局。
- `prefers-reduced-motion`：全部动画直达终态，出场动画不播放。

### 3.5 特效取舍：留一个，砍两个，改一个

| 初代特效 | 决定 | 理由与做法 |
|---|---|---|
| 常驻环带（思考） | **留，改单色** | 思考状态需要一个持续视觉锚点。改成球本体颜色的细环带（墨色/蓝色，低透明度），低倾角水平轨道缓慢环绕；状态结束时 0.5s 回缩消失。不要彩虹色相漂移 |
| 自旋甩带 | **砍，改涟漪** | 彩虹拖尾是玩具感。EVA 切换 / 完成时改用已有的涟漪（圆球荡两圈涟漪 + 窗口泛蓝光），单色、克制 |
| 撒花（完成） | **砍** | 金色五角星 + 彩色方块与"高级工作终端"气质冲突。完成时只用笑弧 + 眨眼 + 一次 +2% 均匀缩放弹出，收尾干净 |
| zzz（睡眠） | **改休眠变暗** | 产品没有睡眠状态。180s 无操作 → 球整体变暗 15%、呼吸放慢到 5s 周期、眨眼停止；任意交互立即唤醒（播一次 `loading` 的交替亮起） |

### 3.6 总结：每处比初代好在哪里

| 维度 | 初代 | 咱们的方案 | 好在哪里 |
|---|---|---|---|
| 表情资产 | 25 组 48 点手写眼环（2400 坐标） | 5 个参数化药丸眼姿态（4 个数字/姿态） | 轻两个数量级，加表情不用重画 |
| 投影 | 轮廓采样 + 钳制 ±1.15 弧度 | 正圆闭式公式，允许到 ±90° | 更精确、无采样误差、眼睛能滑到轮廓线 |
| 注视 | 鼠标驱动 + 正弦微漂移 | grokbot 漫游时刻表（滑行 + 停顿）+ 指针混合 | 没动鼠标时也是活的；停顿让注视读起来"在看"而不是"心神不宁" |
| 眨眼 | 随机定时器 + 关键帧队列 | 确定性时刻表 + 关键帧 + 眨眼藏变形铁律 | 可复现、可测试、不瞬移 |
| 状态数 | 32 种（12 个情绪是死表情） | 14 个工作状态，全部可达 | 没有死表情；多了并行/受阻/检索三个真缺口 |
| 特效 | 彩虹带 + 金色撒花 | 单色环带 + 涟漪 + 均匀缩放弹出 | 气质对：工作终端，不是玩具 |
| 自旋 | 有，但只用于彩带 | 出场 + EVA 切换的仪式感 | spin 有了产品意义，不只是特效触发器 |
| 性能 | rAF 常驻 | 循环只在运动时运行，待机停表；多实例共享 ticker | 省电，后台标签页不空转 |
| 适配层 | 配色 + 语义，球本体不知业务 | 同样结构，但语义映射到引擎事件（thinking/tool/delta/approval） | 球第一次真正"知道"自己在干什么 |
| 错误表达 | 脸色涨红 + 闪动 | 眼睛警觉形 + 轻 shake，身体颜色不动 | 克制：墨色/蓝色是身份色，不拿红色刷脸 |

## 4. 实施步骤与验证方法

### 4.1 实施步骤（5 步，按顺序，不动现有第 1 步的接线）

**第 1 步：数据层（`src/components/mark/expressions.ts`，新建）**
- 把 3.1 的 14 个状态写成声明式配置表，字段照搬初代：`id / group / pool / poolMs / poolSpeed / blinkMs / openness / transition / antics / body / eyes / anims / sequence / gaze`。
- 眼睛姿态用参数化数据（每只眼 `{x, y, scaleX, scaleY, rotate, open, lookX, lookY}`），不要 48 点环。
- 思考池 5 个姿态（P0–P4）先写死，后续可调。
- 验收：`expressions.ts` 能被 `import` 且 14 个状态都有 `transition` 与 `blinkMs`（`null` 也算显式声明）。

**第 2 步：驱动层（`src/components/mark/useBallEngine.ts`，新建）**
- 照搬初代 `engine.js` 的结构，改成 React Hook：`useBallEngine(state) → pose`。
  - 弹簧积分器 `springStep`（子步 1/120，ζ=1.0），三处弹簧：姿态形变、眨眼开合、自旋偏航。
  - 眨眼调度器：确定性时刻表（按状态取间隔：待机 2.5–4s、思考 3.5–7s），关键帧队列（合→停 70ms→1.08 过冲→300ms 落回），14% 连眨。
  - 注视漫游调度器：0.9–1.5s 选目标 → 滑行 0.4–0.6s → 停顿 0.4–0.9s；范围水平 ±7% D、垂直 ±2% D；指针目标混合叠加。
  - 姿态合成：base → sequence → anims → 过渡插值（Cubic 0.3s + 眨眼遮盖）。
  - 待机策略：60s 无操作 → `idle`（已是），180s → 休眠变暗。
  - 全局共享 rAF ticker（多实例单循环，空闲停表）。
- 验收：Hook 在 `idle` 下 3 秒无状态变化时 rAF 停表（用 `performance.now()` 采样或控制台计数验证）。

**第 3 步：渲染层（`Mark.tsx`，重构，不改对外 props 形状）**
- 眼睛改成 3.2 的球面投影：`translateX(R·sin(total)) scale(cos(total), fy·scaleY)`，`cos ≤ 0.02` 隐藏；眼对倾斜 ±3px；间距自然张开。
- 身体改成正圆 + 均匀缩放呼吸（4.6s 慢周期，待机 ±0.5%）；倾身用 `rotate`（±3–6°）；摇摆用缓慢旋转摆动（±2°）；眨眼软沉用均匀缩小 1.5%（禁止宽高比变形、禁止垂直浮动）。
- 呼吸用 CSS `animation`（合成器层），其余用 JS 姿态驱动；只动 `transform` / `opacity`。
- 保留已批准的：药丸眼 20%×30% D、上半部、诺玛墨色 / EVA 蓝色 / EVA 白眼、完成时笑弧。
- 验收：任意尺寸下身体 bbox 宽高比恒为 1.00（逐帧测量）。

**第 4 步：适配层（`src/components/mark/ballAdapter.ts`，新建）+ 接线**
- `paletteFor(mode, theme)`：配色映射。
- `stateFor(agentEvent)`：引擎事件 → 14 个球状态的映射表（3.4）。
- `App.tsx` 接线：`agent-thinking` / `agent-tool` / `agent-tool-result` / `agent-delta` / runDone / approvalPending 全部经过 `stateFor` 再传给 `Mark`；`Mark` 的 props 不变（`state / gaze / fast / eva`），内部改走 `pose`。
- 兜底：未知事件 → `idle` + `console.warn`。
- 验收：发一条消息，全程球的状态按 receiving → thinking → searching/working → replying → done 走一遍，不跳变、不卡在某个状态。

**第 5 步：特效与收尾**
- 思考环带：单色细环（球本体色，低透明度），`thinking` / `parallel` 时显示，退出时 0.5s 回缩。
- EVA 切换：spin 整圈 1200ms + 已有涟漪 + 泛蓝光。
- 完成：笑弧 + 眨眼 + 一次 +2% 均匀缩放弹出（0.3s，无超调），2600ms 后回 `idle`。
- `prefers-reduced-motion`：全部动画直达终态。
- 验收：见 4.2。

### 4.2 验证方法

**A. 巡演模式（可复现的测试台，比初代的 `startTour` 更进一步）**
- 加一个开发态开关（URL 参数 `?ball=tour` 或设置里的隐藏项）：按固定顺序循环 14 个状态，每个停 2.5s，眨眼时刻表用固定种子（不用 `Math.random()`）。
- 固定种子 = 同样的操作永远看到同样的动画，逐帧对比才有意义；录屏后可以一帧一帧数。
- 另加单状态锁定（`?ball=thinking`）：只看某一个状态的循环表现。

**B. 肉眼验证清单（逐项打勾，全部在 100px 主球 + 40px 侧栏小球上各看一遍）**

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 眨眼 | 总时长约 0.2s，闭比开快；眼高最低点约满高的 20%；两眼同步；待机每 2.5–4s 一次，思考态明显放慢 |
| 2 | 眨眼遮盖 | 切换状态时先看到眼闭，睁开时已是新表情；**没有任何一次"睁眼换脸"的跳变** |
| 3 | 张望 | 待机时注视滑行 + 停顿交替，停顿 0.4–0.9s 看得见；不连续扫视；范围不出 ±7% D |
| 4 | 倾身 | 注视向左时球体微向左倾（≤6°），向右时反之；思考时固定 −6°；切换时倾斜角跟着眨眼一起换，不跳变 |
| 5 | 摇摆 | 4.6s 慢周期里身体有轻微旋转摆动（±2°），**中心不动、上下不浮动、宽高比不变** |
| 6 | 呼吸 | 待机均匀缩放 ±0.5%，3.4s/4.6s 循环；工作到来时一次 +2% 脉冲，不循环 |
| 7 | 状态切换 | 每次切换 0.3s 内完成，无超调、无回弹；思考池的 5 个姿态轮换时眼睛是"漂移"过去不是跳过去 |
| 8 | 自旋隐藏 | 出场 / EVA 切换的整圈 spin（1200ms）里，眼睛转到背面时消失、转回来时出现；全程没有眼睛溢出身体轮廓 |
| 9 | 并行 | ultracode 开启工作时，眼睛在 2–3 个点之间跳（每点停 0.8–1.5s），不是连续扫视；每路返回时对应侧眼睛轻眨 |
| 10 | 完成 | 笑弧 + 眨眼 + 一次轻弹出，2600ms 后回待机；没有彩带、没有撒花 |
| 11 | 出错/受阻 | 眼睛收窄 + 轻 shake（≤6px，0.5s 内收住）；身体颜色不变；审批弹窗出现时球同步进 `blocked` |
| 12 | 停止 | 眼睛慢慢收小到半闭后定格，球轻微下沉变暗；不是突然消失 |
| 13 | 小尺寸 | 32–48px 的小球上眼睛依然可读（占比已放大），投影与隐藏逻辑与大球一致 |

**C. 逐帧测量（数字验收，不只靠眼睛）**
- 录屏（60fps）后抽帧核对：眨眼总帧数 ≈ 12 帧（0.2s）；注视停顿帧数 24–54 帧（0.4–0.9s）；spin 总帧数 ≈ 72 帧（1200ms）；状态切换过渡 ≈ 18 帧（0.3s）。
- 身体 bbox 宽高比：任意帧恒为 1.00–1.01（高于 1.01 即存在挤压，失败）。
- 眼睛溢出检查：任意帧眼睛的包围盒完全在身体圆内（被裁剪不算通过——咱们的眼睛是 div 不是 mask 洞，溢出要靠投影数学保证，不是靠裁剪兜底）。
- rAF 停表检查：待机 3s 无变化时，`requestAnimationFrame` 回调停止触发（控制台计数 0 增长）；状态一切换立即恢复。

**D. 回归红线（做完不能丢的东西）**
- 药丸眼 20%×30% D、上半部、诺玛墨色 / EVA 蓝色 / EVA 白眼——尺寸位置颜色一个不改。
- 完成时笑弧、2600ms 回待机、EVA 极淡蓝光晕——已有行为保留。
- `prefers-reduced-motion` 下直达终态。
- `Mark` 对外 props 形状不变（`size / eva / state / gaze / fast`），已有调用方不用改。
