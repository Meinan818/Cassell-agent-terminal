# 卡塞尔专员终端 · 前端终极理念

> 用户 2026-11-13 亲口定：以后加任何新功能、新入口、新界面，都必须先过这一关。**这是铁律，不是建议。**
> 一句话：**现代极简高级，像一个活的产品在呼吸，不是静态页面。**

## 1. 现代极简高级（总纲）
- 极简不是简陋，高级不是堆料。留白、字阶、色阶、动效、克制——五个做到位就是高级。
- 功能可以对标 Codex/Claude，长相绝不照抄。grokbot 的动效语言是美术圣经。
- 目标是 2026 年的现代产品，不是 2012 年的网页。做完自查一遍：有没有残留 2012 年的味道（生硬的框、生硬的按钮、老气的排版、廉价的配色），有就继续改。

## 2. 不要线条，不要线框感（铁律）
- 用户最讨厌线条。分区、分组、卡片，一律不用 1px 框线。
- 用间距、背景色阶、细腻阴影、字重层级建立层次。

## 3. 要有纵深和层次，不能是一张平纸
- 极简高级不是扁平。背景色阶递进、细腻阴影与浮起感、元素层级与呼吸感。
- 每一处分区、每一个浮层、每一个重点都要有纵深感。

## 4. 不要金色
- 全站禁用金色/黄色。强调色只用诺玛墨色与 EVA 蓝。

## 5. 界面里不要照片，不要位图图片
- 用户原话："照片什么的最廉价了"。素材一律用线条矢量、纯色、粒子。
- 校徽用白色线条矢量 CrestLine，忠实还原真校徽，不能像简笔画。

## 6. 不许任何功能"点一下就蹦出来"
- 出现、消失、切换，一律平滑过渡（150–350ms、缓动自然）。没有例外。
- 设置 modal、Cmd-K、Inspector、抽屉、向导、通知、下拉、tooltip、弹窗、侧栏、模式/主题切换、消息入场——全部都要有过渡。

## 7. 全站都要有灵动感和生命感
- 不只是对话区那几处，整个应用都要活起来：侧栏、Inspector、标题栏、问候/空态、Cmd-K、输入框、按钮悬停、开关下拉的微交互。
- 标准：打开第一眼就觉得是一个活的产品在呼吸。保持极简克制、灵动不花哨、快不拖沓。
- 思考动画标准：Grok 式变形图标（笔、球、三点、圆环、文件、文件夹、终端、搜索之间平滑变形 + 对应状态文字），不许用普通转圈、对号、绿药丸糊弄。

## 8. 字体与细节
- 字体固定 Inter + 思源黑体（Noto Sans SC），打包进应用；小字不能有锯齿、不能过细。
- 流式光标是 GPT 式蓝色圆点（8px、#60a5fa、呼吸脉冲），不是竖条。
- 用户消息气泡是 Grok 式（极淡 tint、无边框、大圆角、紧凑贴文字）；悬停按钮脱离文档流，不能留死空白。
- 身份卡是横向名片比例，S 印章是优雅衬线 S + 1px 发丝圆环，无实心圆底，不要"血统评级"文字。
- 侧栏项目行只显示项目名，任务行只显示标题；不要路径副标题、不要"已完成/运行中"药丸。

## 9. 不许假数据
- 从空状态开始，每个功能端到端真正能用。未配 Key 的服务商不能显示假模型、假已连接、假掩码 Key、假时间。

## 新功能验收清单（做完逐条打勾）
- [ ] 现代极简高级吗？像 2026 年的产品吗？
- [ ] 有线框感吗？有金色吗？有照片/位图吗？
- [ ] 有纵深和层次吗？还是像一张平纸？
- [ ] 出现/消失/切换有平滑过渡吗？有没有"蹦一下"的地方？
- [ ] 有灵动感吗？打开第一眼觉得是活的吗？
- [ ] 字体、圆点光标、气泡、身份卡这些细节守住了吗？
- [ ] 有假数据吗？从空状态能真正用起来吗？
